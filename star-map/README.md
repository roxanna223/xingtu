# 星图 MVP

投递腾讯 AI 产品岗的可演示 MVP：**长期对话 → 暗层画像建模 → 2.5D 内心星图 → 状态报告与路径建议 → 反馈闭环**。

产品文档见 `../docs/`：基调文档 `01_foundation_v0.1.md`、功能规格 `02_mvp_spec_v0.1.md`。

## 快速开始

1. `npm install`
2. 复制 `.env.example` 为 `.env`，填入 `DEEPSEEK_API_KEY`（**不填则自动 Mock 模式**，规则引擎兜底，整条链路仍可跑通演示）
3. `npm run dev` → 打开 http://localhost:3000

## 数据导入（7 天演示数据）

1. 按 `../data/7天记录模板.md` 每天记录，复制为 `../data/我的7天记录.md`
2. `npm run import`（自动完成画像抽取与主题归并，支持 LLM 与 Mock 两种引擎）

## 已实现功能

- `/login` 登录/注册页：本地模拟账号体系；注册时**滑动滚轮选出生日期 → 对应星座 → 星座成为星图起点**（不填则"在星海某处"开始）
- `/` 主页：两个大入口——**记录星图** / **和小星聊聊**，问候 + 快捷入口
- `/record` 记录星图：**聊聊记录**（对话节奏干脆：承接 1~2 句轻问"要不要帮你理一理"，语音/文字输入，出可编辑"今日梳理"，心情轨迹一件事多情绪）+ **快速填写** tab
- `/chat` 小星（陪伴 IP）：**用户先开口**——3 条 AI 生成的"快速开始"提示卡（可换一换）；基于画像的陪伴对话；**对话式测验**（你是什么花/小动物/职业方向/今日能量），点选项作答，结果卡自动存入测试报告
- `/star-map` 星图页：2.5D 星图 + 黄道十二星座背景环（用户星座高亮为起点）+ 心情颜色粒子 + 日期 chips 演化回放 + **归类手动矫正**（点开星星：原话可「拆出」成新星星、「合并」到另一颗）
- `/report` 报告页：今日心情色+颜色解读、**叙事优先报告**（回放/带引用的观察/按意图与尺度决定建议/下一句）、逻辑/结果双版本、**报告历史横滑卡片 + 首看即缓存 + 手动重新生成**、**周期报告（周/月/季/年，含趋势）**、观察反馈（说得对/不太对）、反馈回写
- `/tests` 测试报告页：全部测验记录
- 危机信号识别 → 报告置顶转介语与热线 12356

## 目录

- `app/` 页面与 API（Next.js App Router）：`/` 采集页、`/star-map` 星图页、`/report` 报告页
- `lib/` 画像引擎：`store.js` 数据存取、`cohort.js` 代际特征、`prompts.js` 抽取/报告 Prompt、`engine.js` 抽取-归并-报告-反馈闭环
- `scripts/import-diary.mjs` 日记批量导入
- `data/` 运行时画像数据（`profile.json` / `days.json`，自动生成）

## 关键架构决策（面试可讲）

- **主题归并由 LLM 在抽取阶段完成**（输出 `mergeToId` 归并到已有主题）：MVP 不引入向量库，主题数 >100 后再升级 Chroma，这是刻意的复杂度控制。
- **引擎双模**：有 API Key 走 DeepSeek，无 Key 自动降级规则 Mock——演示永远不依赖网络状态。
- **星图先以 SVG 实现可运行基线**（实现规格文档中的降级方案），P1 升级 Three.js 3D 粒子。
