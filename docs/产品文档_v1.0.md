## 一、产品是什么

**一句话**：有长期记忆的 AI 自我状态导航助手——把用户散落的自我叙事，变成一张可回放、可对比、可行动的"内心星图"。

**核心循环（升级版）**：

```
看见 → 理解 → 指路 → 陪走 → 复看 → 回到看见
```

- 看见/理解/指路：已实现（记录 → 抽取 → 星图 → 报告 → 建议）；
- **陪走/复看**：当前阶段的主攻方向（P0 后半程，见第七节）。

**差异定位**：AI 陪伴圈有记忆无指路，AI 命理圈明面玄学单次报告，内心可视化圈单次快照无演化——星图做「长期建模 + 结构化状态 + 可视化 + 路径输出 + 闭环陪走 + 文化接口」的完整闭环。

## 二、为什么做（初心摘要）

详见宪法文档《初心与底色》。四个层次：

1. **起点**：劳累、长痘、晚睡、外卖——"这仅仅是这一刻的回顾，之后又没有自觉"→ 需要**清晰的量化 + 定制化方案**；
2. **泛化**：健康、事业、心理、财富——**清晰是一切的起点**，才能看到差距、看到改变、看到路；
3. **深层**：一切最终指向"认识我自己"（我是谁 / 快乐从哪来 / 人生意义）；道家文化、八字等是自我了解的文化资源，取其文化接口价值、不滑向宿命论；
4. **产品动机**：大部分人都想变得更好，只是需要一个助手——帮人看清自己、看清差距、对齐目标、一步步引领前进，同时顾及身心健康。

**底色原则**：形式可以变（贴合用户是做成的前提），初心不能变。

| 维度 | 定义 |
|---|---|

| 分层交付 | 高认知用户 → 逻辑与规律；结果导向用户 → 直接结论与行动（暗层画像判定，不明面暴露） |

## 四、产品原则（日常决策依据）

1. **助手姿态**：帮人看清、看清差距、对齐目标、一步步引领；不评判、不贩卖焦虑、不替人做决定；
2. **决策三问**：新功能先过——① 帮用户"看清"了吗？② 帮用户"走"了吗？③ 尊重"人"本身了吗（身心健康/自我探索/不制造焦虑）？
3. **清晰优先**：量化明面化以"清晰"为限——趋势、差距、进度可见；不做等级、不做正负标签、不打分定罪；
4. **证据与谦逊**：反编造四机制（证据落地/叙事优先/最小推断/宁可少说）；观察必引用原话，外部信息必标出处；
5. **红线（永不）**：八字/命理排盘与吉凶预测；贩卖焦虑；医疗/治疗承诺（危机信号 → 转介 12356）。

| 安全 | 危机识别 → 12356 转介；明面禁命理词汇；画像可重置 |

### 5.2 数据模型

- `profile.json`：用户（cohort 暗层先验/星座/职业阶段）· 主题节点 · 关联边 · 情绪时间序列 · 行为层 · 报告缓存（日/周期）· 测验记录 · 反馈存证 · adaptLog；
- `days.json`：每日记录（自由倾诉 + 收束三问，q2 心情轨迹"事件（情绪、情绪）"）；
- `chats.json`（P0-1 新增）：对话会话存档（记录/小星两个来源，含逐条消息、抽取标记、covered 标记）。

### P0 补闭环（进行中，Q4 已完成）

| # | 事项 | 目标 | 验收标准 |
|---|---|---|---|

| P0-3（Q6） | 指路验证 | 建议采纳标记 + 主题极性回看；报告输出"上周建议 X，本周 Y 变化" | 同一条建议前后两次报告可见数据差异 |
| P0-4（Q3） | 主页真实化 | 情绪趋势/领域分布/目标对齐度可视化，替代假数值 | 主页数字全部来自真实数据 |

### P1 信息差引擎 v0.1（三支柱补缺）

最小可行知识库（健康/心理/职业/财务，100~300 条人工审校）+ 画像感知检索 + 注入建议环节 + 每条信息标出处。

### P2 目标系统（初心核心的产品化）

目标设定向导（目标 → AI 拆步骤 → 每步量化指标）→ 星图/报告围绕目标展示差距与进度 → 价值层画像 → 冷启动（3 天首图承诺、打卡）。

### P3 规模化（长期）

多用户/账号体系/隐私/成本；行业信息差引擎；文化资源深化（守红线）；对外发布。

### 反清单（当下不做）

❌ 八字排盘与吉凶预测（红线，永不）；❌ 新增娱乐功能；❌ 闭环补完前的 3D 粒子星图、时间轴滑块；❌ 无真实用户数据时的过度设计；❌ 付费体系与真人咨询转介（验证充分后再议）。
