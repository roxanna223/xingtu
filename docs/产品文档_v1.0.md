## 一、产品是什么

**一句话**：有长期记忆的 AI 自我状态导航助手——把用户散落的自我叙事，变成一张可回放、可对比、可行动的"内心星图"。

**核心循环（升级版）**：

```
看见 → 理解 → 指路 → 陪走 → 复看 → 回到看见
```

- 看见/理解/指路：已实现（记录 → 抽取 → 星图 → 报告 → 建议）；
- **陪走/复看**：当前阶段的主攻方向（P0 后半程，见第七节）。

**差异定位**：AI 陪伴圈有记忆无指路，AI 命理圈明面玄学单次报告，内心可视化圈单次快照无演化——星图做「长期建模 + 结构化状态 + 可视化 + 路径输出 + 闭环陪走 + 文化接口」的完整闭环。

## 二、为什么做（初心摘要）

详见宪法文档《初心与底色》。四个层次：

1. **起点**：劳累、长痘、晚睡、外卖——"这仅仅是这一刻的回顾，之后又没有自觉"→ 需要**清晰的量化 + 定制化方案**；
2. **泛化**：健康、事业、心理、财富——**清晰是一切的起点**，才能看到差距、看到改变、看到路；
3. **深层**：一切最终指向"认识我自己"（我是谁 / 快乐从哪来 / 人生意义）；道家文化、八字等是自我了解的文化资源，取其文化接口价值、不滑向宿命论；
4. **产品动机**：大部分人都想变得更好，只是需要一个助手——帮人看清自己、看清差距、对齐目标、一步步引领前进，同时顾及身心健康。

**底色原则**：形式可以变（贴合用户是做成的前提），初心不能变。

## 四、产品原则（日常决策依据）

1. **助手姿态**：帮人看清、看清差距、对齐目标、一步步引领；不评判、不贩卖焦虑、不替人做决定；
2. **决策三问**：新功能先过——① 帮用户"看清"了吗？② 帮用户"走"了吗？③ 尊重"人"本身了吗（身心健康/自我探索/不制造焦虑）？
3. **清晰优先**：量化明面化以"清晰"为限——趋势、差距、进度可见；不做等级、不做正负标签、不打分定罪；
4. **证据与谦逊**：反编造四机制（证据落地/叙事优先/最小推断/宁可少说）；观察必引用原话，外部信息必标出处；
5. **红线（永不）**：八字/命理排盘与吉凶预测；贩卖焦虑；医疗/治疗承诺（危机信号 → 转介 12356）。

### 5.2 数据模型

- SQLite 多用户（users/profiles/days/chats/journals/stream/persona/jobs/events/invites/revoked_tokens）：行级隔离；
- `profiles` 大 JSON：用户（cohort 暗层先验/星座/职业阶段）· 主题节点 · 关联边 · 情绪时间序列 · 行为层 · 报告缓存（日/周期）· 测验记录 · 反馈存证 · adaptLog · 目标 · 进化层 personaMeta；
- `days`：每日记录镜像（日记保存同步写，周期报告兼容）；
- `journals`：日记事实源（date/content/mood）；
- `stream`：人生事件流（日记段落/对话轮/情绪点选，6:00 划日分桶，日报聚合源）；
- `persona`：进化层三文档（self/persona/working，个人资产）；
- `jobs`：夜间作业幂等记录（user_id+day+kind 唯一）。
