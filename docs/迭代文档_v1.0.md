## 二、阶段详述

### 阶段 0：想法与基调

**做了什么**：确认核心痛点（思绪碎片化/单次 AI 对话无记忆/心理测评娱乐化/决策期缺指路）；扫描三类相邻市场（AI 陪伴、AI 命理、内心可视化）确认"长期建模 + 结构化状态 + 可视化 + 路径输出"组合无人做透；定下产品基调（`docs/01`）。

**量化与结论**：主战场 20–35 岁（核心 20–30 岁）；六生活域（事业/关系/自我/健康/财务/成长）× 八情绪体系；"看见 → 理解 → 指路"核心循环；玄学三层包装策略（暗层 cohort 工程化、不排盘）。

**关键决策**：长期记忆优先于单次问答（无记忆=无价值）；画像引擎对用户不可见；心情色不做正负标注（防心理暗示）。

### 阶段 1：MVP v0.1 全链路

**做了什么**：Next.js 15 全栈实现——登录/主页/记录/小星/星图/报告/测验 7 页面 + 13 个 API；双模引擎（DeepSeek + 规则 Mock，无 Key 全链路可跑）；6 套提示词（含反编造四机制、建议四问过滤）；10 框架开场题库；4 套测验；SVG 2.5D 星图 + 星座环；五粒度报告（叙事优先）；像素风全站；10 条人工标注评测集 + LLM 裁判打分脚本。

**量化验证**：
- 领域分类 90%（阈值 85% ✅）；情绪 70%（阈值 75% ⚠️）；危机召回 100% ✅；
- 少样本示例把领域准确率从 60% 拉到 90%（提示词工程收益有实测支撑）；
- 全链路闭环跑通：记录 → 抽取 → 归并 → 星图 → 报告 → 反馈。

**沉淀**：`docs/00~08` 全套设计文档；`data/演示数据-7天日记.md` 兜底演示集。

### 阶段 2：质量修复与补齐（08-23）

**做了什么（P0 三件 + 两件增量）**：
1. 周期报告空数据最小化 + cohort 禁令 + 统一人称（`PERIOD_CACHE_VERSION=2`）；
2. `.env.example` 泄漏的真实 Key 作废占位符化 + git 历史清理（全历史无 Key）；
3. docs/04 报告结构同步（五段式 → 叙事优先）；
4. 星图新增"六域能量"数据卡（每域：主题数/提及占比/主导情绪/情绪色带/最近活跃/域内关联，纯本地规则计算，随演化回放联动）；
5. 部署切换到生产模式（`next build` + `next start`），推送到私有 GitHub（roxanna223/xingtu）。

**尝试与暂停（保留教训）**：制作 20 个月连贯测试集（139 天）导入画像——画像膨胀到 298 个碎片主题 + LLM 大请求频繁挂起导致卡顿，按用户要求暂停。**教训**：长周期数据必须配合主题归并/整理工具（已沉淀 `consolidate-topics.mjs`），不能裸导入。恢复计划已记录在日志。

**踩坑沉淀**：运行中重建 `.next` 会导致缓存污染（PageNotFoundError / 后续发现 API 全 500 空响应），正确姿势是"停服 → 清 .next → 重建 → 启动"。

### 阶段 3：回归初心（08-23）

**做了什么**：创始人口述初心 → 沉淀为宪法级《初心与底色》（起点故事/泛化/认识自我/产品动机/底色五原则/决策三问，含原文摘存）；行业扫描确认 2026 记忆原生智能体为主战场（渡鸦 Raven、微软 Scout、PsyGo 等）；《总策划》定稿——总策略"**把指路升级为陪走，先补闭环再扩能力**"，P0~P3 路线 + 北极星指标 + 反清单 + 调整机制（实际反馈→调研→提案→落地四步；方向不改、路径可调）。

**量化产出**：北极星指标 = 有目标用户中"每周完成一次 回顾→行动→复看 循环"的比例；里程碑 M1~M4；现状诊断结论——"看见 ✅ / 理解 ◐ / 指路 ◐ / 陪走 ❌"，三支柱完成度：心理学 ✅ / 信息差 ❌ / 深度了解用户 ◐。

### 阶段 4：P0-1 对话持久化 + 对话内容入画像（08-24）

**做了什么**：新增 `data/chats.json` 会话制落盘 + `lib/chatStore.js`——记录页对话与小星对话每句消息持久化（用户消息先落盘再等 LLM 回复，LLM 失败不丢）；刷新恢复；保存记录时会话标 covered 防重复抽取；未抽取消息按日期分组走同一套抽取管道，三触发点（记录保存后台链/报告生成前同步/status 攒够 3 条兜底）+ 进程内互斥；控制消息（"[帮我梳理今天]""我选：X"）不参与抽取与行为统计；顺带修复行为信号全量重复计数。

**量化验证（实测）**：开场→2 条消息→落盘 5 句 ✅；刷新恢复 5 句 ✅；保存→会话 covered、全消息标记 ✅；小星 3 条→恢复 6 句 ✅；status 触发消费→画像 6→7 主题（新增"转行产品经理的纠结"）✅；当日已保存→covered 响应 ✅。

**已知取舍**：草稿不随刷新恢复（重新点"帮我梳理"即可）；聊天与记录双通道提及同主题时 freq 双计（mergeToId 保证不重复建点）。

### 阶段 5：P0 验收 · 一周用户路径全模拟（08-24）

**做了什么**：生成一周连贯测试数据（角色"阿宁"：晚睡长痘/项目压力/转行设计/重拾画画；`data/测试数据-一周日记.md`）；编写 `scripts/simulate-user.ps1` + `sim-data.json`，**只以用户身份走产品接口**跑完整路径：注册 → onboarding → Day1~6 快速记录 → Day7 聊聊记录对话流（含模拟刷新）→ 小星（4 轮对话+刷新+花测验+能量提示）→ 当天/历史/周报 → 反馈 → 星图/测验/列表/状态。

**量化结果**：7 天记录、17 主题（5 域）、7 条情绪序列、14 条边、2 份测验、7 份日报 + 1 份周报、2 条反馈、2 个会话正确落盘（记录会话 covered、小星会话未抽取仅剩 3 条控制消息——设计如此）、刷新恢复 100% 成功、当天心情色为真实轨迹混合色（#65999a）。

**发现并修复 2 个真实 Bug**：
1. **换账号数据残留**：auth 用 `Object.assign` 重置画像不全量清键，旧账号 tests/generating/crisisFlag 残留到新账号 → 改为 `defaultProfile` 全量重建 + 清空 chats.json；
2. **小星能量提示偶发失效**：LLM 只回对话不产出结构化 result → 加确定性兜底（能量意图命中但无 result 时规则版补卡；mockStar 正则补"精力"）。

**测试资产**：模拟脚本可直接复用（已处理宿主 PS 5.1 编码坑：ASCII-only + `[char]` 码点 + 原始字节 UTF-8 解码）；运行日志 `simulation-log.txt`。

### 阶段 6：部署准备（08-25）

**做了什么**：确定部署目标为腾讯云学生机 `124.222.89.40`（2 核 4G Ubuntu，系统盘 59G 已用 15G，Swap 2G）；SSH 远程停用服务器上的 OpenClaw 服务（Docker Compose，两个容器：gateway + cli）腾出资源——**只停不删、数据卷完整保留、可一键恢复**（`docker compose start`）。

## 六、迭代方法论沉淀（踩坑库）

1. **运行中重建 `.next` = 事故**：两次导致 API 全 500 空响应。正确流程：停服 → 清 `.next` → 重建 → 启动；
2. **沙箱 spawn EPERM**：`npm run build` 需升级权限（danger-full-access），其余命令不受影响；
3. **宿主 PowerShell 5.1 编码三坑**：BOM-less 脚本按 GBK 读（中文注释可吞 LF 导致下一行变注释）、不支持 `` `u{} `` 转义、JSON 响应按 Latin-1 解码——脚本规范：ASCII-only + `[char]` 码点 + 原始字节 UTF-8 解码；
4. **长周期数据裸导入 = 主题碎片化**（298 主题教训）：先归并再导入；
5. **文档铁律**：任何改动当天记 `docs/10`；改功能/数据模型同步 `00_总文档`；日志只追加不修改；
6. **验收制**：模拟必须走真实用户路径（产品接口），发现的问题先修再复跑——本轮 3 次模拟（2 次发现脚本/产品问题，第 3 次全绿）。
