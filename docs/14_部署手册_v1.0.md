## 0. 最终架构

```
用户浏览器(HTTPS)
   │  域名 your-domain.com(需 ICP 备案)
   ▼
Nginx :443 (certbot 证书,自动续期;仅暴露 80/443)
   │  proxy_pass 127.0.0.1:3001
   ▼
Next.js `next start` :3001(PM2 守护,starapp 非 root 用户,只监听本机)
   │
   ├─ data/ → /opt/star-map/data(profile/days/chats JSON,与版本分离)
   └─ 每日 03:30 cron → /var/backups/star-map/(tar.gz × 7 份)
```

## 3. ICP 备案指南(腾讯云,个人)

### 3.1 前提

1. **域名**:腾讯云(或任何注册商)购买,完成个人实名认证(身份证)。认证后系统数据同步约需 2~3 天才能提交备案。
2. **服务器**:腾讯云服务器,剩余时长 ≥ 3 个月(你的学生机通常 1 年,满足)。
3. **账号**:腾讯云账号完成个人实名认证。

### 3.2 流程(6 步)

1. **入口**:腾讯云控制台 → 搜索「备案」→ [备案控制台](https://console.cloud.tencent.com/beian)(或直接访问 beian.cloud.tencent.com)→ 「开始备案」
2. **填写主体信息**:个人 → 姓名、身份证号、手机号、**通讯地址(须与身份证地址一致或精确到门牌号)**、应急联系电话
3. **填写网站信息**(关键,见 3.3):网站名称、域名、服务内容、网站负责人(本人)
4. **上传材料 + 视频核验**:身份证正反面照片、本人免冠照;**人脸核验**(微信扫码按提示完成,注意背景、光线)
5. **腾讯云初审**:1~2 个工作日,审核员可能来电核实(保持手机畅通)
6. **短信核验 + 管局审核**:
   - 初审通过后,**工信部会向备案手机号发核验短信,须在 24 小时内回复**(链接跳转确认),超时备案自动退回
   - 之后进入**管局审核**(广东省约 7~20 个工作日,各省不同)
   - 通过后获得备案号(如 `粤ICP备XXXXXXXX号`),**须展示在网站底部**

### 3.3 ⚠️ 网站名称与内容的红线(star-map 特别要注意)

个人备案**不允许**「交互式」网站(注册、登录、发帖、聊天等)。star-map 恰好带注册登录 + 对话功能,直接裸奔备案有驳回风险。应对策略:

1. **网站名称**:用个人性质命名,例如「XX 的个人作品集」「XX 的学习记录」。**禁用词**:论坛、社区、平台、商城、网(如"星图网")、中心等。
2. **服务内容**:选「其他」或「个人博客」类,不要选「交互式」。
3. **备案期间展示静态页**:审核期间(以及通过后可能被抽查),建议网站根路径放一个静态「作品介绍页」(无登录入口,纯展示:项目简介 + 截图 + 联系方式)。完整应用放在 `/app` 路径或备案通过后再切换回来。
4. **通过后**:恢复完整应用,网站底部放备案号 + 链接到 beian.miit.gov.cn;首页同时放隐私政策入口(清单 D 组)。

> 风险提示:各地管局尺度不同,若审核被问「网站是否有注册登录」,如实说明为「个人作品演示、不对外运营」;若被要求整改,按审核意见去掉登录入口再提交。

### 3.4 备案期间服务器怎么办

- 备案期间**域名不能解析到服务器**提供服务,但服务器本身可以继续用 IP 访问开发调试。
- 腾讯云会检测未备案域名解析,直接拦截 80/443 端口流量——所以「先挂域名再补备案」走不通,顺序必须是**先备案、后解析**。

### 3.5 公安备案(备案通过后 30 天内)

- 平台:[全国互联网安全管理服务平台](https://www.beian.gov.cn)(注册 → 新增主体 → 新增网站,填 ICP 备案号与服务器信息)
- 审核 1~3 天,通过后把公安备案号也放到网站底部。部分地区不强制,但建议做,免费。

## 5. 服务器一次性初始化

1. 上传部署脚本并修复行尾(Windows 写出的 .sh 可能是 CRLF):

```powershell
scp deploy\prepare-server.sh deploy\deploy-app.sh deploy\backup.sh root@124.222.89.40:/root/
```

```bash
ssh root@124.222.89.40
sed -i 's/\r$//' prepare-server.sh deploy-app.sh backup.sh
chmod +x prepare-server.sh deploy-app.sh backup.sh
./prepare-server.sh
```

脚本完成:系统更新、Nginx+certbot、Node.js 20、PM2、starapp 用户、`/opt/star-map` 目录、备份 cron、logrotate、fail2ban。

2. 部署应用:

```bash
./deploy-app.sh /root/star-map-release.tar.gz
```

脚本完成:解压 → 数据迁移到持久目录 → `npm ci` + `npm run build` → PM2 启动(starapp 用户)→ 开机自启。

3. 编辑 `.env`(填 Key + 会话密钥):

```bash
vi /opt/star-map/current/.env
# DEEPSEEK_API_KEY=sk-你的新key(不填则 Mock 模式)
# SESSION_SECRET=$(openssl rand -hex 32)   ← 手动粘贴生成结果
sudo -u starapp pm2 restart star-map   # 使 .env 生效
```

4. **多用户初始化(首次部署必做,生成密码请立即记录到本手册 §5.6 演示账号台账)**:

```bash
cd /opt/star-map/current

# ① 迁移 JSON → SQLite(anning 保留为演示账号,密码在此设置)
AN_PW=$(openssl rand -base64 12 | tr -dc 'A-Za-z0-9' | head -c 12)
sudo -u starapp node scripts/migrate-to-sqlite.mjs "$AN_PW"
echo "演示账号密码: $AN_PW"        # ← 记录到 §5.6 台账

# ② 创建管理员账号(admin,密码在此设置)
ADM_PW=$(openssl rand -base64 12 | tr -dc 'A-Za-z0-9' | head -c 12)
sudo -u starapp node scripts/seed-admin.mjs admin "$ADM_PW"
echo "管理员密码: $ADM_PW"         # ← 记录到 §5.6 台账

sudo -u starapp pm2 restart star-map
```

> 迁移幂等:已迁移则跳过;重复部署不会覆盖线上数据。若需重建演示账号:先 `--force` 再迁移。
> 旧 JSON 自动归档到 `/opt/star-map/data/legacy-json/`,确认无误后可删。

5. **管理员生成邀请码**(登录 admin → `/admin` → 邀请码 tab → 生成);注册链接即 `http://IP:3001/login`。

6. 验证:

```bash

# 期望: {"loggedIn":false,"user":null}
# 再登录 anning/admin 走一遍完整链路(或参考 scripts/test-multi-user.mjs)
```

## 7. 域名 + Nginx + HTTPS(备案通过后)

1. 腾讯云 DNS 解析:添加 A 记录 `@` 和 `www` → `124.222.89.40`
2. 安装 Nginx 配置:

```bash
cp /opt/star-map/current/deploy/nginx-star.conf /etc/nginx/sites-available/star-map
sed -i 's/YOUR_DOMAIN/你的域名/g' /etc/nginx/sites-available/star-map
ln -s /etc/nginx/sites-available/star-map /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

3. HTTPS(certbot 自动签发 + 自动续期,并自动加 80→443 跳转):

```bash
certbot --nginx -d 你的域名 -m 你的邮箱 --agree-tos --no-eff-email
```

4. 安全组(腾讯云控制台 → 轻量/CVM 防火墙):
   - 放行:22(建议限制来源 IP)、80、443
   - **关闭**:18789 等一切其他端口;若演示期用 `IP:3001`,记得演示后关掉 3001

## 8. 备份与恢复

- 自动:每天 03:30 打包 `/opt/star-map/data` → `/var/backups/star-map/`,保留 7 份
- 恢复(把某天备份放回去):

```bash
sudo -u starapp pm2 stop star-map
tar -xzf /var/backups/star-map/star-data-<时间戳>.tar.gz -C /opt/star-map/data
sudo -u starapp pm2 start star-map
```

- 建议再开一个**异地副本**:腾讯云 COS 免费额度内,`backup.sh` 末尾加一行 `coscli cp` 即可(P1)

## 10. 故障排查速查

| 现象 | 排查 |
|---|---|
| 页面打不开 | `sudo -u starapp pm2 status`;`curl http://127.0.0.1:3001/api/status`;`tail /var/log/star-map/err.log` |
| 登录 401 | cookie 是否被清;`Secure` cookie 只在 HTTPS 下生效(IP+HTTP 访问时浏览器不存 cookie → 属预期,演示期建议用 HTTPS 域名或接受每次刷新重登) |
| 登录 429 | 同 IP 失败 5 次锁 15 分钟:`pm2 restart star-map` 可清空(进程内限流) |
| 忘记密码 | `sudo -u starapp node /opt/star-map/current/scripts/reset-password.mjs '新密码'` |
| 内存吃紧 | `pm2 monit`;应用上限 500M 自动重启;整机 4G 下正常占用 <1G |
| 证书过期 | certbot 已自动续期,`certbot renew --dry-run` 可验证 |
| 备案被驳回 | 按驳回意见改(最常见:网站名称/通讯地址/幕布照问题),重新提交 |
