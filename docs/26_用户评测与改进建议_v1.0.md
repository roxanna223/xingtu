# 星图用户评测与改进建议 v1.0

> 评测性质：模拟目标用户（20–35 岁人生转折期）对当前全量功能的端到端体验评测。
> 评测目标：找出体验与功能上的不足，对照产品目标（初心 / 总策划 / 北极星指标），给出可落地的改进建议与优先级。
> 评测时间：2026-08-29（当前代码版本含 P0 全部 + P1/P2 已实现项）。

---

## 一、评测背景与方法

### 1.1 评测对象

当前星图已实现功能（基于代码与文档盘点）：

| 模块 | 已实现 |
|---|---|
| 账号 | 注册/登录（邀请码选填）、onboarding（出生日期→星座/cohort）、注销、管理后台 |
| 主页 | 两大入口（和小星聊聊 / 写日记）、目标提醒、快速开始引导卡 |
| 日记 | 打开即当天、情绪点选、一句话起笔、自由书写自动保存、今日一问、语音输入、月历回顾（仅当月） |
| 小星 | 聊天、记录引导（梳理卡存日记）、个性化建议卡、测验（花/动物/职业/能量）、目标拆解 |
| 星图 | 2D SVG 像素星图 + 3D 引力视图切换、星座环、六域能量卡、星星拆分/合并/改名、按日期回放 |
| 报告 | 日/周/月/季/年五粒度、6:00 划日、三坐标（目标/自我/差距）、成长规划、心情色、历史清单 |
| 计划 | 目标拆解、步骤完成、积分、每日彩蛋、完成轨迹 |
| 设置 | 注销、XiaoXing 进化资产查看（self/persona/working） |
| 评测脚本 | 抽取评测、对话质量 4 维裁判、心理数据集转换器 |

### 1.2 评测方法

- **模拟用户画像**：选取三类典型目标用户，分别走完整路径；
  - **用户 A（23 岁，在途期）**：研究生三年级，秋招焦虑，对 AI 产品熟悉但期望高效；
  - **用户 B（27 岁，立业期）**：工作 3 年，转行纠结，深夜 emo 场景，需要被承接；
  - **用户 C（32 岁，转折期）**：考虑创业/婚育，需要长期视角与目标对齐。
- **路径覆盖**：注册 → 首次使用 → 写日记 → 小星聊天/引导 → 查看星图 → 查看报告 → 设定目标 → 反馈。
- **对照基准**：
  - 产品目标：《初心与底色》《总策划》《产品文档》；
  - 北极星指标：有目标用户中“每周完成一次 回顾 → 行动 → 复看 循环”的比例；
  - 产品原则：助手姿态 / 决策三问 / 清晰优先 / 证据与谦逊 / 红线。

## 二、模拟用户旅程记录

### 2.1 用户 A（23 岁，在途期，秋招焦虑）

**路径**：注册 → 写日记 → 小星引导 → 星图 → 报告 → 设定目标

**体验记录**：

1. **注册登录**：看到“邀请码（选填）”字样，犹豫了一下“没有邀请码能不能进”。输入昵称密码后直接进入，但**出生日期选择器是滚轮样式**，第一次不知道可以点，试了两次才选对。
2. **首页**：两大入口很清楚，但 Hero 文案“你的内心星图，会演化”有点抽象。下面的快速开始卡片第一张是“帮我理一理今天”，直接点了进入小星。
3. **小星记录引导**：小星说“我在。想从哪说起，我就陪到哪。”——等待用户先开口，**没有主动开场**，A 愣住了 5 秒不知道说什么。建议卡里有“秋招焦虑”相关话题，点了之后才开始聊。梳理卡出来后发现字段很多（summary、3 个 moments、signals、unsaid、tomorrow），**编辑负担重**，直接点了“存进日记”。
4. **日记**：回到日记页，内容已经进来了，但**没有明显的“已保存”提示**，担心没存上，又手动点了保存。月历只能看当月，想回顾上周面试那天，但上周日期**点不了**（不能翻月）。
5. **星图**：2D 像素风格很喜欢，星星可以点开看详情。切换 3D 后**没有说明颜色含义**，不知道蓝紫色代表焦虑。时间轴回放只有日期 chip，没有连续动画。
6. **报告**：当天报告还没生成（6:00 刷新），看到的是“生成中”。第二天打开，三坐标里的“差距”写“今天还看不出明显差距”，**觉得没收获**。成长规划给了一条“明天先改简历第一版”，挺具体，点了“已做到”，但**不知道这个反馈会改变什么**。
7. **目标设定**：通过聊天说“我想做目标拆解”，生成了计划，但主页没有明显的“去计划栏目”入口，自己找了半天。

**核心卡点**：首次使用无引导；梳理卡过重；报告延迟生成且可能空；反馈无感知。

### 2.2 用户 B（27 岁，立业期，深夜 emo）

**路径**：直接小星聊天 → 测验 → 报告 → 反馈

**体验记录**：

1. **小星聊天**：凌晨 1 点打开，直接说“最近好累，不想干了”。小星承接了情绪，但**没有检测到今天日期变更**（6:00 划日），回复里还是“今天”而不是“昨天”。对话质量裁判脚本测过，但 B 不知道这个功能存在。
2. **测验**：点了“测一测我是什么花”，3 题流程顺畅，结果存到测试报告。但**测验结果没有与画像/报告联动**，感觉像一次性娱乐。
3. **报告**：第二天看报告，心情色是蓝灰色，但**没有解释颜色混合逻辑**，只看到“今天的颜色主要来自低落”。三坐标“自我”部分写“用户呈现低落情绪”，觉得**太笼统，不像“懂我”**。
4. **反馈**：点了“没帮助”，但没有提示“我们会记住你的反馈，下次报告会不一样”。**反馈像黑洞**。

**核心卡点**：凌晨体验不连贯；测验结果无后续；报告“自我”部分太泛；反馈无闭环感知。

### 2.3 用户 C（32 岁，转折期，创业/婚育）

**路径**：写日记 → 目标拆解 → 星图 → 报告 → 复看

**体验记录**：

1. **日记**：自由书写体验好，语音输入在 Safari 不支持，提示“请用 Chrome 或 Edge”，**移动端劝退**。情绪点选 8 个词，但“迷茫”和“低落”分不清。
2. **目标拆解**：说“我想拆解创业计划”，生成了步骤，但**步骤没有量化指标**，只有“完成市场调研”这种主观描述。计划页可以看到进度，但**没有与星图/报告联动**（比如“创业焦虑”主题没有和创业目标关联）。
3. **星图**：3D 视图很酷，但**星星太多时重叠**，看不清名字。没有“只看某个生活域”的筛选。
4. **报告**：周报里“成长规划”建议“和伴侣聊聊婚育计划”，但 C 觉得自己上周已经聊过了，**建议没有感知到历史**。没有“每周回顾”入口，C 不知道需要定期回来看。
5. **复看**：没有“上周我建议你 X，你做到了吗”的回顾入口，北极星指标里“回顾→行动→复看”循环**没有显性产品化**。

**核心卡点**：移动端语音不可用；目标拆解无量化指标；建议不感知历史；复看循环无入口。

## 三、体验问题清单（按严重度）

| 严重度 | 问题 | 影响用户 | 具体表现 |
|---|---|---|---|
| 🔴 P0 | **首次使用无引导** | 新用户 | 注册后直接丢进首页，不知道先做什么；3 天首图承诺未实现 |
| 🔴 P0 | **报告延迟生成且可能为空** | 所有用户 | 6:00 懒生成，用户当天打开看到“生成中”；证据不足时“差距”字段为空，觉得没收获 |

| 🟡 P1 | **梳理卡字段过多** | 所有用户 | summary + 3 moments + signals + unsaid + tomorrow，编辑负担重，多数用户直接存 |

| 🟢 P2 | **数据导出 UI 缺失** | 高级用户 | 个人资产可导出（数据层已具备），但无 UI 入口 |

## 五、目标对照评估

### 5.1 初心五原则

| 原则 | 达成度 | 说明 |
|---|---|---|
| 助手姿态 | ✅ | 不评判、不贩卖焦虑、危机转介已实现 |
| 决策三问 | ◐ | “帮用户看清”已达成；“帮用户走”部分达成（目标系统有但循环不完整）；“尊重人”已达成 |
| 清晰优先 | ✅ | 不做正负标签、不打分定罪 |
| 证据与谦逊 | ◐ | 观察引用原话已达成；但“自我”部分有时太泛，建议不感知历史 |
| 红线 | ✅ | 禁命理、不诊断、危机转介已实现 |

### 5.2 北极星指标

**有目标用户中“每周完成一次 回顾 → 行动 → 复看 循环”的比例**

- **现状**：❌ 无产品化入口。用户不知道需要定期回来看报告，也没有“上周我建议 X，你做了吗”的回顾提示。
- **差距**：复看环节完全缺失；行动环节（目标系统）有但无量化；回顾环节（报告）有但无提醒。

### 5.3 三支柱完成度

| 支柱 | 完成度 | 说明 |
|---|---|---|
| 心理学 | ✅ | 承接情绪、共情、轻引导已实现 |
| 信息差 | ❌ | 信息差引擎未实现，建议中无外部信息 |
| 深度了解用户 | ◐ | 状态层✅（主题/情绪/关联）；行为层◐（规则版）；价值层❌（立场/红线/偏好未做） |

## 六、改进建议与优先级

### P0（本周必做，直接影响北极星指标）

| # | 改进项 | 具体动作 | 验收标准 |
|---|---|---|---|
| 1 | **首次使用引导 + 3 天首图承诺** | 新用户注册后进入引导页，明确“连续 3 天记录，生成你的第一张星图”；主页加进度提示“已记录 X/3 天” | 新用户 3 天内留存率提升；3 天首图完成率可统计 |
| 2 | **报告“差距”不空 + 反馈闭环感知** | 证据不足时“差距”写“今天记录还看不出明显差距，明天可以试试多记一点”；反馈后 toast 提示“已记住，下次报告会不一样” | 用户反馈后次日报告可见变化；反馈率提升 |
| 3 | **每周回顾入口 + 复看提醒** | 主页加“本周回顾”入口；报告页加“上周建议→本周变化”板块；每周日推送/提醒（站内信） | 有目标用户每周回顾率可统计；复看率提升 |
| 4 | **目标拆解量化指标** | 每个步骤必须带量化标准（如“完成 3 次简历修改”）；计划页显示量化进度 | 步骤可量化率 100%；目标完成率可统计 |

### P1（下两周，补三支柱与核心体验）

| # | 改进项 | 具体动作 | 验收标准 |
|---|---|---|---|
| 5 | **小星记录引导主动开场** | 进入引导模式后，小星主动抛一个具体问题（基于画像/最近记录），如“最近秋招还顺利吗？” | 引导完成率提升；新用户首次引导成功率提升 |
| 6 | **梳理卡简化** | 默认只显示 summary + 1 个 moment，其他字段折叠；保存后自动跳转日记页并 toast“已存进日记” | 梳理卡保存率提升；编辑时间缩短 |
| 7 | **日记月历翻页 + 语音 fallback** | 月历支持前后翻月；语音输入不可用时提示“当前浏览器不支持，可用文字输入”并隐藏按钮 | 回顾功能使用率提升；移动端可用性提升 |
| 8 | **建议感知历史 + 信息差引擎 v0.1** | 周报/月报建议必须引用历史（如“上周你提到 X，这周建议 Y”）；接入 100 条人工审校知识库，建议带出处 | 建议重复率下降；信息差建议被认可率可统计 |
| 9 | **价值层画像 v0.1** | 从对话/日记中抽取立场/红线/偏好（如“重视家庭”“不接受加班”），注入报告“自我”部分 | “自我”部分个性化率提升；用户觉得“懂我”比例提升 |

### P2（第三周，体验优化与高级功能）

| # | 改进项 | 具体动作 | 验收标准 |
|---|---|---|---|
| 10 | **星图 3D 图例 + 筛选** | 3D 视图加图例说明（颜色=情绪）；支持按生活域筛选；星星重叠时自动分散 | 3D 使用率提升；用户理解度提升 |
| 11 | **进化资产解释页** | 设置页加“小星如何记住你”说明，解释 self/persona/working 三文档用途；加导出按钮 | 个人资产查看率提升；导出功能可用 |
| 12 | **移动端适配 + 视觉微调** | 验证并修复移动端布局；视觉从像素风向更治愈/专业微调（保留像素元素但减少生硬边框） | 移动端使用率提升；用户满意度提升 |

## 七、验收标准（对照北极星指标）

### 7.1 P0 验收

- **3 天首图完成率**：新用户注册后 3 天内完成首次星图生成的比例 ≥ 60%；
- **反馈闭环感知率**：用户反馈后，次日报告中可见基于反馈的变化（如“你上次说建议太难，这次换简单一点的”）；
- **每周回顾率**：有目标用户中，每周至少打开一次报告页的比例 ≥ 40%；
- **目标量化率**：目标拆解步骤中带量化指标的比例 = 100%。

### 7.2 P1 验收

- **引导完成率**：记录引导模式从开始到保存梳理卡的比例 ≥ 50%；
- **建议历史感知率**：周报/月报中建议引用历史记录的比例 ≥ 70%；
- **信息差建议认可率**：带外部信息建议中，用户标记“有帮助”的比例 ≥ 50%；
- **价值层画像准确率**：从对话中抽取的立场/红线/偏好，用户确认“说得对”的比例 ≥ 60%。

### 7.3 P2 验收

- **3D 使用率**：星图页 3D 视图切换率 ≥ 30%；
- **移动端留存**：移动端用户 7 日留存率与桌面端差距 ≤ 20%；
- **数据导出率**：高级用户中使用导出功能的比例 ≥ 10%。
