# 「星图」下一轮迭代方向 v1.0（基于 7 天真实反馈的提案）

> 性质：提案文档（总策划调整机制第三步"提案"）。触发 = `docs/29_七天真实记录_数据验收与反馈汇总_v1.0.md` 的 25 条真实反馈。

## 一、方向判断（结合产品定位）

**定位（锚点不变）**：星图的全部价值 = 让用户更省力地缩小"现在的我"与"想成为的我"之间的距离。量化是手段、**差距是枢纽**、引领是终点。

**7 天真实数据说了三件事**：

1. **用户对"功能"无感，对"懂我"有感**——F24"我希望产品能更懂我，而不是给我没用的东西"、F25"这些功能一般般"。功能堆叠不再产生价值，只有"更懂我"才有价值；
2. **载体不可信时，一切价值归零**——F8 承接句跨 3 天串台、F5 输入框被锁死、F2 卡片关不掉。小星是"引领"的唯一载体，载体先要可信，差距和懂我才递得出去；
3. **差距的出口必须诚实与日更**——F13"生成中"误导、F15 目标"居然是一次性的"、F17 改了记录日报没反馈。差距不在"报告页"，而在"每一天的出口"上。

**迭代方向一句话**：**先把载体做可信（T4），再把差距做显性（T5），最后把"懂我"做出来（T6）——三条线依次推进，不并行铺开。**

## 二、批次 1 · T4：小星引领模型四拍 + 梳理重建（可信）

**对应反馈**：F1~F12（A 组 7 条 + B 组 5 条）。

### 做到什么程度（验收，全部用创始人原话）

| 验收项 | 标准 |
|---|---|
| 对话式梳理 | 说"帮我梳理"→ 小星在对话里一步步问、帮你理，**不再甩卡片**（"是你来引导我去梳理"） |
| 输入自由 | 梳理中/生成中**任何时刻输入框可用 + 自动聚焦**，不用再点一下（"输入框是我的自由"） |
| 结果可见 | 梳理内容直接出现在对话框里、卡片可正常关闭（F2/F4） |
| 追加不覆盖 | 梳理结论**新增**进日记，不覆盖已写内容；入口文案="梳理对话到日记"（F3） |
| 不串台 | 连续 5 轮对话不出现跨会话承接句串台（"外卖不好吃"事故不复现，F8） |
| 可纠正 | 用户说"你说错了/记忆错乱"→ 小星承认、问清、记入画像（F9/F10） |
| 概念边界 | 建议卡与星图节点区分清楚：点卡是"发起一句话"，不是"星图里的一条记录"（F11/F12） |

### 改的具体点

1. **提示词重写**：`starMessages`/`starGuideMessages` 改为**四拍**——①接住（情绪承接）②照见（把他的处境/模式说给他听）③给一步（被卡住/开口要时给最小一步）④陪走（记住这一步，下次问起）；删除"建议是报告阶段的事"；
2. **梳理重建**：`[帮我梳理]` 触发**对话式引导**（小星按四拍逐轮引导），产出"一句话小结 + 今天最想改变的一件事"，以消息形式出现在对话里（不是编辑卡）；`draft-card` 编辑 UI 删除，只保留"📖 存进日记"轻条；
3. **输入框修复**：chat 页输入框在任何状态（busy/生成中/引导中）都可输入；进入会话自动聚焦（`autoFocus`）；
4. **串台修复**：跨会话记忆引用必须带日期锚点（"你 08-31 说过…"），无锚点不引用；删除"我在听。你说到『X』的事，慢慢说"这类模板承接句；persona 注入只保留置信度 ≥0.5 的条目；
5. **说错话纠正**：检测用户纠正语义（"你说错/记错/记忆错乱"）→ 对应 instinct 条目置信度 −0.1 并承认、问清；
6. **梳理入日记**：梳理结论以追加段落写入当日 journal（`content + '\n\n【小星梳理】…'`），绝不覆盖原文；
7. **建议卡文案**：卡片明确是"发起一句话"，与星图节点视觉/文案区分。

## 三、批次 2 · T5：报告差距核心化 + 目标日更（差距）

**对应反馈**：F13~F18（C 组 6 条）+ T2 已做的"今天的一步"延续。

### 做到什么程度（验收）

| 验收项 | 标准 |
|---|---|
| 生成诚实 | 报告页不再出现误导性"正在生成"；文案写明"明天 6:00 生成"；对话**不足 N 轮不触发生成**（F13/F14） |
| 报告差距核心 | 报告第一句 = 差距（进行中目标 vs 今天）；"目标"坐标与"差距"坐标口径统一（修 Day 3 观察：目标坐标不能写"今天没有明确表达目标"）；无目标时给出"想成为的样子"第一步（R4） |
| 目标日更 | 计划页每天显示"今天走没走"；短期目标日更、长期目标按周期检查（目标分型：daily / weekly / monthly）（F15/F16） |
| 修改有反馈 | 改了日记/记录 → 次日日报出现"你今天更新了 X"（F17） |
| 周期诚实 | 周期报告覆盖按用户使用跨度（记录跨两周时，周报不得只报 1 天就下结论）（F18） |
| 即时小结 | 日记保存后**立即**给出"今天小结"轻量卡，不等次日 6:00（R6） |

### 改的具体点

1. `reportMessages`：coordinates.gap 空值时不再输出"看不出差距"式免责，改为输出差距的种子（"今天还没说清想要什么——先把'想成为'说一句"）；goal 坐标注入进行中目标；
2. 报告生成触发：当日对话轮数阈值（如 ≥5 轮或日记保存）才在访问时生成；页面文案"明天 6:00 生成昨天与今天"；
3. 目标分型：goal 增加 `period` 字段（daily/weekly/monthly）；计划页步骤行显示今日状态；长期目标只在周期节点提醒；
4. 修改反馈：journal 更新时写 stream 事件 → 次日日报 prompt 注入"今天更新过"信号；
5. 即时小结：日记保存后台链生成轻量"今天小结"（复用三坐标结果，不进报告缓存），当天可看；
6. 周期报告：period 定义按用户实际使用跨度调整（连续区间而非自然周）。

## 四、批次 3 · T6：价值层画像 v0.1 + 测验沉淀（懂我）

**对应反馈**：F19~F25（D/E/F 组 7 条）。

### 做到什么程度（验收）

| 验收项 | 标准 |
|---|---|
| 懂我 | 报告/小星能说出"你在意什么 / 回避什么 / 什么让你有能量 / 你想成为什么"，创始人认"它懂我"（F24 原话验收） |
| 情绪诚实 | 情绪点选后置或可跳过（不强制、不误导）；情绪判断以内容抽取为主、允许人工修正（F19） |
| 日记自由 | 日记纯自由书写，无任何限制性输入（F20） |
| 测验沉淀 | 测验有明面入口；结果写入画像并进日报；同测验重复做可纵向对比（F22/F23） |
| 题库 | 测验主题 ≥10 个（人工策划 + 已有沉淀机制复用） |

### 改的具体点

1. **价值层抽取**：新增价值层抽取提示词（在意什么/回避什么/反复模式/能量来源/想成为什么）→ 重写 persona `self` 文档（去掉职业阶段等标签堆叠，换成"人的描述"）；注入小星与日报 prompt；
2. **情绪点选 UX**：日记页情绪选择后置（保存时可选、可跳过）；日报情绪解读以当天内容抽取为准；
3. **测验入口与沉淀**：测验入口明面化（聊天工具栏固定入口）；测验结果写入画像并注入日报（"上次测是 X，这次 Y"）；题库扩充至 ≥10；
4. **功能收敛**：以"懂我"为唯一标准复查现有功能（F25），无用的继续砍。

## 五、纪律与不做清单

- **顺序**：批次 1 → 2 → 3，每批完成才进下一批；每批验收用真实用户（创始人）原话用例，不用模拟数据；
- **不回潮**：T1 已砍的（积分/彩蛋/3D/星座/cohort）不因任何理由恢复；
- **不做**：新页面、视觉装修、新娱乐功能、信息差引擎（P1 继续冻结）、部署与运营投入（F1~F6 冻结项继续冻结）；
- **文档纪律**：每批完成同步 `00_总文档` 与 `产品文档`（T1/T2 遗留的"待同步"一并清偿）；
- **秘书纪律**：每批按秘书协议开工（锚点卡→行为句→三问→追踪器→完工核对→偏差日志）。
