## 一、策划总纲（一页纸）

- **使命（初心一句话）**：帮人看清自己、看清差距、对齐目标、一步一步引领前进，成为心中的自己——同时顾及身心健康。
- **产品一句话**：有长期记忆的 AI 自我状态导航助手——把散落的自我叙事，变成可回放、可对比、可行动的"内心星图"。
- **核心循环（升级版）**：看见 → 理解 → 指路 → **陪走** → 复看 → 回到看见。**加粗两段是当前阶段要补齐的闭环后半程。**
- **差异化**：长期建模 + 结构化状态 + 可视化 + 路径输出 + 闭环陪走 + 文化接口（中国式自我叙事）。
- **目标人群**：20–35 岁人生转折期人群，核心 20–30 岁（在途期 / 立业期 / 转折期）。
- **北极星指标**：有目标的用户中，"每周完成一次 回顾 → 行动 → 复看 循环"的比例。

## 二、起点与依据

### 2.1 初心宪法（摘引）

- **起点**：劳累、长痘、晚睡、外卖——"这仅仅是这一刻的回顾，后续又没有自觉了"→ 需要**清晰的量化 + 定制化方案**。
- **泛化**：健康、事业、心理、财富——清晰是一切的起点，才能看到差距、看到改变、看到路。
- **深层**：一切最终指向"认识我自己"；道家文化、八字等是自我了解的文化资源。
- **动机**：大部分人都想变得更好，只是需要一个助手。
- **底色**：形式可以变，初心不能变。（全文见《初心与底色_v1.0.md》，冲突时以宪法为准）

### 2.2 现状诊断（2026-08-23）

- **看清** ✅：记录/星图/五粒度报告已全链路运行；
- **看到差距与改变** ◐：有报告，无目标参照、无建议后复看；
- **一步步引领** ❌：Q4 对话不持久化、Q5 反馈只存不消费、Q6 建议无效果验证、Q3 主页假数值；
- 三大支柱：① 心理学 ✅ · ② 信息差 ❌ · ③ 深度了解用户 ◐（状态层✅/行为层◐/价值层❌）。
- **结论：星图现在是一个"复盘型助手"，要成为初心要的"引领型助手"，缺的是闭环后半程——"陪走"。**

### 2.3 行业依据（2026-08 扫描）

记忆原生智能体已成行业主战场（自进化记忆框架"渡鸦 Raven"、微软个人 AI 助理 Scout、"可养成"数字搭档 PsyGo、带记忆的 AI life coach 等）。两层含义：**方向被验证**；同时"长期记忆"正在变成标配——**我们的差异化必须押在：闭环陪走 + 文化接口 + 信息差引擎。**

## 三、产品原则（日常决策依据）

1. **助手姿态**：产品是助手——帮人看清、看清差距、对齐目标、一步步引领；不评判、不贩卖焦虑、不替人做决定。
2. **决策三问**：任何新功能先过三问——① 帮用户"看清"了吗？② 帮用户"走"了吗？③ 尊重"人"本身了吗（身心健康/自我探索/不制造焦虑）？
3. **清晰优先**：量化明面化以"清晰"为限——趋势、差距、进度可见；不做等级、不做正负标签、不打分定罪。
4. **证据与谦逊**：反编造四机制；观察必须引用用户原话，外部信息必须标注出处。
5. **红线（永不）**：八字/命理排盘与吉凶预测；贩卖焦虑；医疗/治疗承诺（危机信号 → 转介 12356）。

## 四、主干路线（分阶段）

### P0 补闭环（1~2 周）——决定产品性质

**目标**：把"指路"升级为"陪走"，走通"记录 → 报告 → 采纳 → 复看 → 可见变化"全链路。

| # | 事项 | 对应缺口 | 初心对应 |
|---|---|---|---|
| 1 | 对话持久化 + 对话内容入画像 | Q4 | "通过对话丰富数据"（现在刷新即蒸发） |
| 2 | 反馈消费闭环：观察反馈回写画像、adaptLog 真实落盘、连续负反馈切换路径 | Q5 | 助手要"听得进" |
| 3 | 指路验证：建议采纳标记 + 主题极性回看，报告可输出"上周建议 X，本周 Y 变化" | Q6 | "看到改变"的实锤 |
| 4 | 主页真实化：真实趋势可视化（情绪趋势/领域分布/目标对齐度） | Q3/D1 | 底色原则"清晰优先" |

**验收**：用 7 天真实数据跑通全链路；对同一条建议，前后两次报告可见基于数据的差异。

### P1 信息差引擎 v0.1（第 3~4 周）——补三支柱缺的那根

**目标**：给用户"他原本不知道的信息"，打开眼界、打破思路僵局。

- 最小可行知识库：健康 / 心理 / 职业 / 财务 curated 内容 100~300 条（人工审校）；
- 画像感知检索：先读用户画像 → 检索 → 注入"建议"环节 → **每条信息标注出处**（与反编造原则一致）；
- 同期冻结新增娱乐功能（测验等维持现状）。

**验收**：建议中出现用户没说过、但有出处的相关信息，且被用户认可相关。

### P2 目标系统（第 2~3 月）——初心核心的产品化

**目标**：落地"对齐目标、一步一步引领"。

- 目标设定向导：用户说目标（变健康/转行/理财）→ AI 拆阶段步骤 → 每步量化指标；
- 星图/报告围绕目标展示"差距与进度"；
- 价值层画像（立场/红线/偏好）——支柱③补全，"知道用户喜欢听什么"；
- 冷启动：3 天首图承诺、打卡提醒。

**验收**：≥1 位用户带目标使用 2 周后，能说"它让我看到了差距"。

### P3 规模化（长期）

- 多用户/账号体系/隐私/成本控制；行业信息差引擎；文化资源深化（守红线）；对外发布与获客。
- 远期愿景（仅陈述）：人生导航基础设施——阶层/时代知识库、真人咨询转介、付费体系；均在验证充分后再议。

## 五、验证体系（用初心的方法做产品）

- **北极星指标**：有目标的用户中，"每周完成一次 回顾 → 行动 → 复看 循环"的比例。
- **过程指标**：建议采纳率 / 主题极性回升率 / 7 日留存 / 画像利用率（报告引用画像的比例）。
- **评测**：报告质量 rubric、评测集扩到 50+、双人标注、情绪抽取再校准（现 70% < 75% 阈值）。
- **用户节奏**：先 1 个真实用户（创始人 7 天记录）→ 5~10 个种子用户 → 再谈扩张。**每阶段设量化验收，验收不通过不进下一阶段。**

## 七、调整机制（方向不改，路径可调）

本文档是主干，不是教条。**触发调整的只能是实际反馈，不是一时想法。**

1. **触发条件**：真实用户反馈、评测数据、留存/采纳数据与预设明显不符；行业出现重大变化。
2. **调整流程（四步，缺一不可）**：
   - ① **记录**：现象原样记入迭代日志（docs/10），不急于改；
   - ② **调研**：先搞清楚原因——用户访谈、数据复盘、竞品/行业研究、小范围实验；
   - ③ **提案**：写明"改什么、为什么、预期影响、风险、验收"，并对照初心三问、五原则、红线逐条审查；
   - ④ **落地**：通过后更新本文档（版本 +1）+ 相关设计文档 + 迭代日志；新路径重新设验收。
3. **不可调**：初心五原则、红线、北极星方向、助手定位。
4. **可调**：阶段顺序与范围、功能取舍、技术选型、时间表、指标阈值、呈现形式。

1. 任何改动当天记迭代日志（docs/10）；改功能/数据模型/提示词同步 `00_总文档`。

5. 文档链路：初心（宪法）→ 本文档（总纲）→ 00（技术归档）→ 01~09（设计）→ 10（日志）。冲突时上层优先。
