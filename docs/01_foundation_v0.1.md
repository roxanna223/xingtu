# 「星图」产品基调文档 v0.1（内部稿）

> 产品代号：「星图」（备选：观我 / 心象 / StellarMind）。本文档是后续所有讨论与实现的"宪法"，先定基调，再谈细节。

## 0. 一句话定位

面向 20–35 岁人生转折期人群的 **AI 自我状态导航产品**：通过长期对话持续建模用户的内在状态，将其可视化为一张 **会演化的"内心星图"**，并输出一条明确的下一步路径。

**核心循环：看见 → 理解 → 指路。**

## 1. 背景与问题

### 1.1 用户痛点（按严重度排序）

1. **思绪碎片化、焦虑泛化**：想法多但散落在不同生活领域，缺乏整体视角，内耗严重。
2. **单次 AI 对话无记忆**：豆包、DeepSeek 等只能承接"一次表达"，聊完即忘，无法形成对用户的长期认知——这正是本产品要突破的点。
3. **心理测评娱乐化**：市面心理测试停在娱乐标签层（MBTI 式），测完无后续，无行动路径。
4. **人生决策期缺"定位+指路"服务**：实习、求职、考研考公、转行、婚育等关键节点，用户"不知道自己现在处于什么状态、下一步该做什么"；专业咨询贵、门槛高。

### 1.2 市场机会（扫描结论）

三个相邻市场各有单点方案，**无人做透组合**：

| 圈子 | 代表产品 | 做到了什么 | 缺什么 |
|---|---|---|---|
| AI 陪伴/记录 | 心光、Me.bot | 长期记忆、日记复盘 | 无状态结构化、无路径输出 |
| AI 命理 | 人生K线、DeepChow | 命理报告可视化 | 明面玄学、单次报告、娱乐向 |
| 内心可视化 | 心镜、知镜、情绪星图、Loom | 状态→星图快照 | 单次快照，无演化、无指路 |

→ **机会窗口：`长期建模 + 结构化状态 + 可视化 + 路径输出` 的完整闭环，目前没有完整竞品。**

## 2. 目标用户

- **主战场：20–35 岁，核心 20–30 岁人生转折期人群。**
- 三段细分：
  1. **20–23 在途期**：本科高年级/研究生——实习、求职、升学抉择。
  2. **23–27 立业期**：初入职场 1–3 年——方向摇摆、内耗、价值感缺失。
  3. **27–35 转折期**：转行、晋升、婚育、创业等重大决策。
- **分层交付策略**（由暗层画像判定，不在明面暴露）：
  - 高认知用户 → 给逻辑与规律（状态成因、心理学概念、推导过程）。
  - 结果导向用户 → 直接给结论与行动建议，原因一句话带过。
  - 判定依据：对话中的信息密度、抽象词使用率、追问行为等暗层信号。

## 3. 产品目标

- **MVP 目标（本周内）**：跑通"记录 → 星图 → 报告 → 反馈微调"最小闭环，能演示 7 天演化。
- **阶段验证目标**：验证"星图演化 + 指路"对目标用户的感知价值（不是验证"聊天陪伴"）。
- **愿景**（仅陈述，不做进 MVP）：成为每个人的人生导航器——让更多人成为自己想成为的人。宏观层（时代 cohort、阶层矛盾映射个人）写进 roadmap 文档，不占用 MVP 资源。

## 4. 核心机制（产品逻辑）

闭环五步：

1. **采集**：每日/多轮对话记录（文字为主），开场引导 + 自由倾诉 + 3 个收束提问，保证抽取质量。
2. **建模**：暗层画像引擎抽取「主题-情绪-关联」三元组 → 聚类到生活域 → 更新用户状态 JSON。
3. **呈现**：2.5D 星图（MVP）/ 3D 粒子星图（迭代）。粒子=念头主题，区域=生活域。
4. **指路**：状态报告 = 当前状态判定 + 压力根因链 + 一条明确路径建议。
5. **反馈**：用户对报告/建议的反馈 → 回写画像 → 星图微调 → 回到 1。

**关键设计决策：**

- **长期记忆优先于单次问答**：无记忆 = 无价值，这是与通用聊天产品的分界线。
- **画像引擎对用户不可见**（类比大模型不向用户展示内部文档）：避免被拆解感，保持"它懂我"的体验。
- **星图的信息增量（防"炫技"质疑的标准答案）**：颜色=心情（八种情绪各一个专属颜色，刻意不做正负向标注——避免心理暗示，用户才愿意真实表达）、亮度=活跃度、位置=生活域、连线=关联、时间轴=演化——把"散落的自我叙事"变成"可回放、可对比的趋势数据"。

## 5. MVP 功能范围

### P0（必做，作品集主体）

| 模块 | 功能点 |
|---|---|
| 对话采集 | **常驻对话（主）**：AI 承接情绪、跟随节奏，用户示意后产出可编辑"今日梳理"（含情绪轨迹）；快速表单（辅）保留补录 |
| 画像引擎 | LLM 抽取三元组 → 生活域聚类 → 画像 JSON 存储（含 cohort 先验注入） |
| 星图页 | 2.5D 分区粒子星图：缩放/旋转/点击粒子看详情卡片 |
| 状态报告页 | 状态判定 + 压力根因链 + 路径建议 + 分层话术切换 |
| 反馈入口 | 报告页"有帮助/没帮助"+ 一句话反馈 → 回写画像 |

### P1（时间允许）

- 星图时间轴回放（演化动效，核心记忆点）
- 每日打卡提醒
- 3D 粒子升级

### 暂不做（只写入 roadmap）

阶层/时代知识库、真人咨询转介、付费体系、八字全量排盘、多模态记录。

## 6. 星图设计规范（2.5D MVP 版）

- **画布**：深空背景，2.5D 固定视角 + 缩放/旋转。
- **粒子**：一个粒子 = 一个念头主题（如"转行焦虑""和父母的关系"）。
- **属性映射**：
  - 颜色 → **心情颜色**：八种情绪各一个专属颜色（焦虑=蓝紫、疲惫=灰蓝、迷茫=雾灰、愤怒=红、平静=青绿、期待=金、低落=深蓝、充实=暖橙）。**刻意不做"正向/负向"标注**：负向标签是心理暗示，会让用户伪装自己、不再信任产品。内部 polarity 数值仍用于计算（报告、权重），只是不向用户展示。
  - 大小/亮度 → 提及频率 × 近期活跃度
  - 连线 → 主题共现关联，线宽=关联强度
- **区域**：生活域分区。初版六域：**事业 / 关系 / 自我 / 健康 / 财务 / 成长**（可再议）。
- **交互**：拖拽旋转、滚轮缩放、点击粒子 → 详情卡片（主题名、情绪、关联主题、原文引用）。
- **P1 演化**：时间轴滑块 → 粒子移动/明灭 = 状态随时间演化。

## 7. 状态报告结构（v0.2 改版：叙事优先，证据落地）

1. **今日心情色**：颜色块 + 一句话颜色解读；
2. **心情轨迹**：客观数据——事件 × 情绪（可多条），附主导域/活跃主题；
3. **今日回放**：用用户自己的话客观重述今天发生了什么（不评价、不补因果）；
4. **我注意到**：2~3 条观察，**每条附用户原话作证**；证据不足宁可少说；
5. **可以试试**：可执行的一小步建议（仅当用户表达了困扰/目标，否则不出现）；
6. **下一句**：明天的一个具体话题。

**反编造原则（报告生成的架构）**：证据落地（观察必须引用原话）→ 叙事优先（先重述事实）→ 最小推断（禁止把 cohort/人生任务写成判定依据）→ 宁可少说（不为填模板凑内容）。

## 8. 文化符号资产策略（三层包装法，定稿）

1. **暗层工程**：出生日期 → cohort 静态特征（时代代际、成长经济周期、年龄对应的人生任务，如 25–30 立业期 vs 35–40 转型期）→ 作为画像先验注入 LLM。**不做实时排盘。**
2. **文档口径**：定位为"**文化符号资产的工程化使用**"——中国用户习惯用命理语言自我叙事（"我命不好""最近水逆"），产品需要把这套文化隐喻翻译为可计算的 cohort 特征，才能与用户对齐认知框架。这体现对目标用户的深层洞察。
3. **面试口径**：命理语言是用户自我叙事的文化接口，**不是科学依据**。

**红线：明面绝不展示八字/六爻内容，不预测吉凶，不贩卖焦虑（合规 + 用户信任）。**

## 9. 技术方案（MVP）

- **前端**：React + react-three-fiber（2.5D 星图）。页面清单：采集页 / 星图页 / 报告页 / 反馈组件。
- **后端**：Python FastAPI 或 Next.js API Routes（与前端同栈更省事，倾向 Next.js）。
- **模型**：DeepSeek API 为主，预留混元 API 接口（投腾讯的加分项：研究过目标公司生态）。
- **存储**：SQLite/JSON 存画像 + 向量库（Chroma）检索历史对话。
- **玄学暗层**：出生日期 → 静态 cohort 特征表（预置映射，不调外部排盘服务）。

## 10. 数据模型（初版）

- **用户画像 JSON**：基本信息、cohort 特征、主题节点列表、情绪时间序列、生活域分布、反馈历史。
- **主题节点**：id、名称、生活域、首现时间、最近活跃时间、情绪均值、原文引用列表。
- **关联边**：source、target、权重、共现上下文。

## 11. 风险与合规

- **心理边界**：识别危机信号（自伤/自杀倾向）→ 输出转介与干预热线提示；产品定位为"自我认知工具"，**非医疗、非治疗**。
- **玄学合规**：暗层使用、不预测吉凶、不制造焦虑。
- **数据隐私**：画像透明可见、支持一键删除；demo 阶段本地存储。
- **冷启动**：7 天才有完整图谱，用户为何坚持？→ 新手引导承诺"3 天出首图"、每日打卡提醒；MVP 演示用预置/自采数据绕开，文档中保留解法。

## 12. MVP 验收标准

- **功能闭环**：录入 ≥7 天记录 → 生成星图与状态报告 → 用户反馈后星图/报告可见变化。
- **演示脚本**：90 秒"星图演化"动效 + 报告解读 + 反馈微调演示（这是作品集灵魂）。
- **成功指标（演示用）**：反馈回写的可见性、报告认可率（自测）、7 天数据完整性。

## 13. Roadmap

- **v0.1（本周）**：MVP 闭环，2.5D 星图。
- **v0.2**：3D 粒子 + 时间轴演化 + 分层话术增强。
- **v0.3**：打卡机制、多模态记录、危机转介接口。
- **愿景**：阶层/时代知识库、行业信息差引擎 → "人生导航"基础设施。
