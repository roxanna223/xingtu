# 「星图」智能体自迭代机制设计 v0.1（SCALE 式）

> 目标：让记录 Agent 与「小星」根据用户的行为、语言、反馈、态度持续自我校正，越来越贴合用户——这是产品长期壁垒的核心。
> 原则：所有调整可审计（adaptLog）、不越红线、用户可见范围内的变化永远温和渐进。

## 1. 三层画像（迭代的数据基础）

| 层 | 内容 | 更新频率 | 现状 |
|---|---|---|---|
| 状态层 | 主题/情绪/生活域/关联（已有 topics、emotionSeries） | 每次记录 | ✅ 已实现 |
| 行为层 | 语言风格、开放深度、情绪表达频率、抽象思考倾向、提问频率、偏好主题、反馈倾向 | 每次对话后滚动更新 | ✅ 规则版已实现（`lib/behavior.js`），LLM 深度抽取见 roadmap |
| 价值层 | 用户重要立场/价值观/红线（如"坚决不考研""拒绝被催促"） | LLM 周期复盘时抽取 | 🔜 roadmap |

## 2. 信号来源（输入）

1. **记录对话**：开场问题的回答长度与深度 → 判断"具体型/意象型"用户；
2. **小星对话**：话题选择、追问行为、情绪词密度；
3. **报告反馈**："有帮助/没帮助"+ 原因 → 路径建议类型偏好（已有回写，可扩展为路径风格）；
4. **测验行为**：测什么、答多快、对结果的反馈；
5. **使用节律**：记录时段、频率、中断点（下次记录时"昨天聊到一半"的衔接线索）。

## 3. 迭代对象（输出：参数化 Prompt）

| 迭代对象 | 依据信号 | 落地方式 | 现状 |
|---|---|---|---|
| 开场问题选择 | openDepth / 偏好主题 / 昨日记录 | 心理学框架轮换 + 行为摘要注入 | ✅ 已实现（10 框架轮换 + forcedOpener） |
| 收束节奏 | openDepth（浅→更快收束） | behaviorSummary 注入记录 Prompt | ✅ 已实现 |
| 共情强度 | 情绪表达频率 | behaviorSummary 注入 | ✅ 已实现 |
| 解释深度 | 抽象思考倾向（高→讲逻辑，低→给例子） | behaviorSummary 注入 | ✅ 已实现 |
| 小星话题推荐 | 偏好主题 + 状态层 | suggestions Prompt 已带画像 | ✅ 已实现 |
| 报告分层话术 | personaTier | 已有 | ✅ 已实现 |
| 测验结果个性化 | 三层画像 | 结果生成时注入 | ✅ 已实现（"正在立业期的你"） |
| 价值观遵循 | 价值层 | Prompt 注入"用户重要立场，勿触碰" | 🔜 roadmap |
| 周期自我复盘 | adaptLog | 每 7 天生成"画像修正摘要"并回写 | 🔜 roadmap |

## 4. 迭代闭环（SCALE 式五步）

1. **S-Sense**：采集信号（本轮已落地行为层规则采集：平均句长、情绪词密度、抽象词密度、提问频率的滚动加权）；
2. **C-Context**：信号归一为三层画像（behavior 字段，滚动衰减，防单次噪声）；
3. **A-Adapt**：画像注入各 Agent 的参数化 Prompt（forcedOpener / behaviorSummary / profileSummary）；
4. **L-Log**：每次调整写入 `profile.adaptLog`（时间、触发信号、调整项、旧值→新值），保证可解释可回滚；
5. **E-Evaluate**：评测闭环——eval-set（抽取质量）+ 对话质量 rubric（开场具体度/共情恰当/收束时机）+ 用户反馈指标（报告帮助率、次日留存）。

## 5. 护栏（不可迭代的部分）

- **红线词表**：政治、极端、歧视、教唆内容，所有 Prompt 硬性禁用；
- **玄学边界**：命理仅暗层 cohort 特征，明面禁用（已有）；
- **心理安全**：危机信号 → 热线 12356（已有）；画像分析不得给用户贴疾病标签；
- **一致性**：价值层一旦记录（如用户明确表达过立场），后续建议不得与其冲突；冲突时宁可少说；
- **渐进性**：任何风格调整只做小幅偏移（如收束节奏每次只快 10%），不做剧烈翻转，避免用户感知"AI 变了个人"。

## 6. 现状落地 vs Roadmap

**已落地（v0.1）**：
- 行为层规则采集与滚动更新（记录/小星双通道）；
- behaviorSummary 注入记录/小星/报告 Prompt；
- 开场问题 10 框架心理学题库 + 轮换指针 + forcedOpener；
- 报告反馈回写、persona 分层、测验结果个性化。

**Roadmap**：
- v0.2：LLM 深度行为抽取（语言风格/价值观/回避主题）+ 价值层画像 + 价值观遵循注入；
- v0.3：周期自我复盘（每 7 天用 adaptLog 生成"画像修正摘要"，人工/自动确认后回写）；
- v0.4：对话质量 rubric 自动化 + A/B 指标（报告帮助率、次日留存）。
