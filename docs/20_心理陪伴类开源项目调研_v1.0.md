## ② 分项目深挖

### 1. EmoLLM —— SmartFlowAI/EmoLLM（推荐重点看「工程化流水线」）

- **仓库 / 主页**：https://github.com/SmartFlowAI/EmoLLM （1780★，MIT，活跃，最近推送 2026-06-18）
- **一句话定位**：支持「理解用户 → 支持用户 → 帮助用户」心理健康辅导链路的开源大模型全家桶，覆盖数据构建、增量预训练、指令微调、RAG、评测、部署。
- **核心机制**：
  - **多底座微调矩阵**：InternLM2/2.5（1.8B/7B/20B）、Qwen / Qwen1.5 / Qwen2、Baichuan2-13B、ChatGLM3-6B、DeepSeek MoE-16B、Mixtral-8x7B、LLaMA3-8B、GLM4-9B、DeepSeek-R1-14B 等，提供全量 / LoRA / QLoRA 多套微调配置文件（如 `internlm2_5_chat_7b_full.py`、`qwen_7b_chat_qlora_e3.py`）。
  - **数据构建**：`generate_data` 目录用**多角色 GPT 生成**（模拟咨询师/来访者）产出 QA 对与多轮对话；仓库内包含 `data_pro.json`（场景更全）、`aiwei.json`（角色扮演、带 Emoji）等；多轮部分直接采用 **CPsyCounD**。
  - **评测**：`evaluate/` 提供「专业评估」（Professional_evaluation，用 LLM 打分）+ 客观指标计算；其效果被 ESC-Eval（情感支持对话评测）引用。
  - **RAG + 部署**：提供检索增强 pipeline、并发加速、WebDemo、GGUF 量化版等。
  - **里程碑**：EmoLLM V3.0 = 基于 CPsyCounD + InternLM2.5-7B-Chat 全量微调（与 CPsyCoun 团队合作）。
- **与星图的关联点**：
  - ✅ **工程化流水线**：其「数据构建 → 微调 → 评测 → RAG → 部署」的完整链路是星图后续若从 DeepSeek API 走向自托管/微调时的最佳参考模板。
  - ✅ **评测方法**：LLM-as-judge 专业评估可直接映射到「小星对话质量裁判」。
  - ⚠️ **角色化定位冲突**：EmoLLM 大量采用「爹系男友/温柔御姐/老母亲」等角色扮演，与星图「不评判、不贴人格标签、不制造焦虑」红线**相悖**；借鉴其工程，但不可照搬其角色化与话术风格。
  - ❌ 未见专门的**危机识别/转介**模块（README 有「免责声明」）。
- **可借鉴资产**：微调配置脚本、数据构建教程、RAG pipeline、专业评测 prompt、GGUF 部署方案。
- **风险**：仓库 MIT，但**模型权重分散在 ModelScope / OpenXLab，需逐个核对权重许可**；角色化心理模型有制造不当情感依赖的伦理风险；部分底座（如 Baichuan）许可需确认。

### 2. MindChat —— X-D-Lab/MindChat（漫谈）

- **仓库 / 主页**：https://github.com/X-D-Lab/MindChat （718★，GPL-3.0，最近推送 2024-09-13，低活跃但未归档）
- **一句话定位**：「漫谈」心理大模型，主打中文情感支持对话，基于 Qwen/Baichuan/InternLM/ChatGLM 多底座微调。
- **核心机制**：
  - 基于真实心理咨询语料 + 心理 QA + 多轮对话，用 QLoRA/LoRA 微调各底座（Qwen-7B、Baichuan-13B、ChatGLM2-6B、InternLM-7B 等）。
  - 演进：MindChat-Qwen2-4B/7B、MindChat-8B；后续 **MindChat-R0**（2025，ECNU 论文）引入**强化学习**做情感支持对话。
- **与星图的关联点**：可作为「中文情感支持对话」的**参考基线**，对比小星在共情、陪伴上的表现；MindChat-R0 的 RL 思路可作为「对话质量对齐」的方向参考。
- **可借鉴资产**：各底座微调权重（HF/ModelScope）、QLoRA 微调教程。
- **风险**：**仓库 GPL-3.0（代码传染性），直接改代码再分发需开源**；权重许可需逐个确认（多数底座如 Qwen 为 Apache-2.0 友好）；无危机处理模块；低活跃。

### 3. SoulChat —— scutcyr/SoulChat（灵心健康）

- **仓库 / 主页**：https://github.com/scutcyr/SoulChat （762★，Apache-2.0，最近推送 2024-06-15，低活跃）
- **一句话定位**：通过「长文本咨询指令 + 多轮共情对话」混合微调，提升大模型的**共情（Empathy）/倾听（Listening）/安慰（Comfort）**三能力。
- **核心机制**：
  - **数据集 SoulChatCorpus**：以咨询师/来访者**角色扮演**构建多轮共情对话，每条含「长文本咨询指令」（来访者背景/处境/诉求的详细描述）+ 多轮共情回复（规模数万级，未逐条核实）。
  - **训练**：LoRA 微调 ChatGLM2-6B / InternLM-7B / Baichuan2-7B / Qwen-7B。
  - **SoulChat2.0**：心理咨询师「数字孪生」方向。
  - 论文 EMNLP 2023 Findings：[arXiv:2311.00273](https://arxiv.org/abs/2311.00273)。
- **与星图的关联点**：
  - ✅ **最高价值之一**：「共情-倾听-安慰」三能力分解，可直接映射到小星的共情话术模板（先倾听共情 → 再安慰 → 再引导），与「承接情绪」强相关。
  - ✅ SoulChatCorpus 的「长文本咨询指令」结构，与小星「引导用户讲清处境/情绪」的记录场景契合，可借鉴其指令字段设计。
- **可借鉴资产**：SoulChatCorpus（共情话术样本）、LoRA 微调方案。
- **风险**：Apache-2.0 较友好；学术导向、低活跃；无危机处理模块；「安慰」能力若过强需防「情绪依赖」，与星图「不制造焦虑、不替代专业治疗」需平衡。

### 4. CPsyCoun —— CAS-SIAT-XinHai/CPsyCoun（推荐重点看「咨询框架 + 评测」）

- **仓库 / 主页**：https://github.com/CAS-SIAT-XinHai/CPsyCoun （256★，数据集 CC-BY-4.0，ACL 2024 Findings，最近推送 2025-05-21）
- **一句话定位**：基于**咨询报告**重构多轮咨询对话 + 自动评测的框架，产出数据集 CPsyCounD、评测集 CPsyCounE、模型 CPsyCounX。
- **核心机制（字段/流程级）**：
  - **对话重构 Memo2Demo**：分两步 —— **Memo Conversion**（把咨询报告转成结构化「记忆」）+ **Demo Generation**（由记忆生成高质量多轮咨询对话）。
  - **咨询报告规范化**：按中国国家二级心理咨询师考试等文献，把报告规约为 **6 部分：Title（标题）、Type（类型）、Method（疗法）、Case Brief（个案简述）、Consultation Process（咨询过程）、Experience Thoughts（经验感悟）**。
  - **CPsyCounD**：共 **3,134 条多轮咨询对话**（LLaMA-Factory 格式开源）。
  - **评测 4 维**：**Comprehensiveness（全面性，来访者问题反映程度）/ Professionalism（专业性）/ Authenticity（真实性）/ Safety（安全性 = 来访者隐私保护）**。
  - **Turn-Based 评测法**：把 m 轮对话拆成 m 个单轮，每轮带历史 `h_i` 让 LLM 生成回复 → 逐轮用 LLM 按 4 维打分 → 取平均作为整段对话得分。**这套「逐轮 + 带历史 + LLM 评分」的裁判法可原样复用到小星。**
  - **CPsyCounX**：InternLM2-7B-Chat 全量微调（9 epochs、batch 448、lr 1e-6）。
  - **CPsyCounE**：9 个主题的多轮对话评测集。
  - **CPsyCounR**：原始咨询报告数据集（需签《隐私数据保护协议》后才提供，敏感）。
- **与星图的关联点**：
  - ✅ **P0 最高价值**：①「6 部分咨询报告结构」可直接映射到小星的「引导记录/个人定位/目标拆解」结构化模板；②「4 维评测 rubric + 逐轮裁判法」可直接做成小星对话质量裁判；③ CPsyCounE（9 主题）可作评估集。
  - ⚠️ 其「Safety」= 隐私保护，**不是危机转介**，不能替代星星的 12356 危机红线机制。
- **可借鉴资产**：CPsyCounD（CC-BY-4.0，可署名后用于微调）、CPsyCounE、4 维评分 prompt、咨询报告 6 部分模板。
- **风险**：数据集 CC-BY-4.0（需署名）；CPsyCounX 权重许可需确认；CPsyCounR 涉隐私不可直接取用；模型 7B 规模有限。

### 5. SMILE / MeChat —— qiuhuachuan/smile

- **仓库 / 主页**：https://github.com/qiuhuachuan/smile （535★，仓库 CC0-1.0，EMNLP 2024 Findings，最近推送 2024-11-17）
- **一句话定位**：用 ChatGPT 把「单轮咨询回复」扩写成「多轮共情对话」，产出 SmileChat 数据集（55k 多轮）与 MeChat 模型。
- **核心机制**：
  - **Single-turn → Multi-turn Inclusive Language Expansion**：以单轮心理咨询回复为种子，让 ChatGPT 扮演来访者/咨询师补全多轮，并注入「共情、不评判」等 inclusive language（包容性语言）。
  - **SmileChat**：共 **55,165 条多轮对话**（论文 [arXiv:2305.00450](https://arxiv.org/abs/2305.00450)）。
  - **MeChat**：在 SmileChat 上微调（原始底座 LLaMA-7B，社区有 Qwen 版 GGUF）。
- **与星图的关联点**：55k 多轮共情对话可作为「多轮共情话术」参考语料；其「单轮扩多轮」的数据增强方法可借鉴，用于小星多轮引导对话的语料扩充。
- **可借鉴资产**：SmileChat 数据集、扩写 prompt 思路。
- **风险**：仓库 CC0-1.0（宽松），但 **MeChat 模型权重许可以 HF 模型卡为准，倾向非商用（需确认）**；数据由 ChatGPT 生成，可能引入幻觉/风格偏差，用于训练前需清洗。

### 6. MentalLLaMA —— SteveKGYang/MentalLLaMA

- **仓库 / 主页**：https://github.com/SteveKGYang/MentalLLaMA （323★，MIT，最近推送 2024-03-04，停更倾向）
- **一句话定位**：首个**可解释心理健康分析**的开源指令模型，针对社交媒体文本做多任务分类 + 解释生成。
- **核心机制**：
  - **IMHI 基准**：约 **105k 样本 / 19k 指令**，来源 Reddit（英文）+ 新浪微博（中文），含 **8 个子任务**（如是否抑郁/焦虑等二分类、多分类、以及「为什么这样判断」的**解释生成**）。
  - **模型**：在 LLaMA2-7B/13B 上指令微调（`MentalLLaMA-chat-7B/13B`），另出中文版基于 Baichuan（`MentalLLaMA-chat-7B-Chinese`）。
  - 评测：心理健康预测用 F1，解释质量用人工评估。论文 [arXiv:2309.13567](https://arxiv.org/abs/2309.13567)。
- **与星图的关联点**：
  - ⚠️ 场景差异大：它是**社交媒体文本分类/可解释分析**，不是陪伴对话，不能直接当小星底座。
  - ✅ 对**危机信号识别**有借鉴：其「抑郁/自伤语义分类 + 解释」的思路，可作星图「自伤/自杀语义识别」的**辅助信号参考**（尤其中文微博版）；但不可直接套用，需在星图自有数据上重训/验证。
- **可借鉴资产**：IMHI 数据集（MIT）、分类 + 解释的任务定义。
- **风险**：语料偏 Reddit/微博，与中文陪伴对话分布差异大；中文微博数据涉个人隐私，商用/再训练前需评估；学术导向。

### 8. Psy-LLM / PsychoLex（诚实标注）

- **Psy-LLM**：论文 [arXiv:2307.11991](https://arxiv.org/abs/2307.11991)《Psy-LLM: Scaling up Global Mental Health Psychological Services with AI-based Large Language Models》。思路是抓取中文心理咨询平台问答数据训练 LLaMA2，并扩展多语言。**未找到统一官方 GitHub 仓库/权重**（仅论文 + 相关解读）。
- **PsychoLex**：检索不到与「心理大模型」相关的同名仓库（命中的都是无关的 lexer/词表项目），**判定为误记或不存在**，本调研不采纳。
- **替代同族「Psy-*」项目**：
  - [PsycoLLM（MindIntLab-HFUT）](https://github.com/MindIntLab-HFUT/PsycoLLM)：中文心理健康对话大模型，Apache-2.0，74★。
  - [PsyLLM（Emo-gml）](https://github.com/Emo-gml/PsyLLM)：《Beyond Empathy: Integrating Diagnostic and Therapeutic Reasoning with LLMs》，54★，未声明许可。
  - **注意**：PsyLLM「整合诊断与治疗推理」的定位与星图「非医疗、非治疗」红线**直接冲突**，只能当反面边界参考，不可引入其诊断话术。

| 对话框架 | 角色化辅导链路 | 情感支持（未结构化） | 共情-倾听-安慰 | **咨询报告 6 部分结构化** | 单轮扩多轮 | 无（分类任务） | 依赖 PsyQA | 诊断/治疗倾向 |
| 多轮能力 | 中（用 CPsyCounD） | 中 | **强（多轮共情）** | **强（3134 多轮 + 逐轮评测）** | **强（55k 多轮）** | 弱 | 弱 | 中 |
| 危机处理 | ❌ 无（仅免责声明） | ❌ 无 | ❌ 无 | ⚠️ 仅「Safety=隐私保护」 | ❌ 无 | ⚠️ 分类抑郁/自伤信号（非转介） | ❌ 无 | ❌ 无 |

## ④ 对星图的可借鉴结论（按模块 + 优先级）

### P0 —— 借鉴框架当提示词设计（零成本、立即能用，最重要）

1. **咨询报告 6 部分结构（CPsyCoun）→ 小星「引导记录 / 个人定位」模板**
   用 `Title / Type / Method / Case Brief / Consultation Process / Experience Thoughts` 六段式，重写小星的记录引导 prompt，把「承接情绪 → 引导记录 → 目标拆解」流程结构化。
2. **共情-倾听-安慰三能力（SoulChat）→ 小星共情话术模板**
   小星每轮回复内部分解为「先共情（看见情绪）→ 倾听确认（复述处境）→ 安慰/陪伴 → 再引导下一步」，与「不评判、不贴标签」天然契合。
3. **CPsyCoun 4 维评测 rubric（全面性/专业性/真实性/安全性）→ 小星输出质检清单**
   把这 4 维改写为小星的自检 prompt（尤其是「真实性=不编造、安全性=隐私保护 + 危机转介」），作为系统级输出约束。
4. **PsyQA 的「助人策略 / 帮助度」字段 → 小星话术策略分类**
   借鉴 PsyQA 的 strategy 标注（倾听、共情、提问、建议、鼓励等），为小星建立「当前应采用哪种助人策略」的隐式决策维度。

### P0 —— 用数据集与评测当「评估裁判」（用于回归验证对话质量）

5. **CPsyCounE（9 主题多轮）+ 4 维评分**：作为小星多轮对话的**自动化裁判集**，每次改 prompt 后跑回归。
6. **PsyBench / C-Eval 心理子集**：评估小星**心理学知识底座**是否扎实（防「瞎给建议」），可定期抽样跑。
7. **IMHI / SMHD 分类信号**：作为「危机语义识别」的**评测素材**（星图自研分类器时用其标注思路与负样本分布参考）。
8. **PsyQA（strategy/helpfulness）**：做「共情话术是否到位」的软性裁判参考。

### P1 —— 直接用开源权重当「对话质量基线」（对比 DeepSeek API）

9. **MindChat / SoulChat / EmoLLM(InternLM2.5-7B) / CPsyCounX / MeChat**：部署一个 7B 级开源心理模型作为**对照基线**，与小星（DeepSeek 大模型）跑同一批评测集，量化「自研提示词 + 大模型」相比「专用微调小模型」的增量。
10. 结论预期：7B 级专用模型的共情风格或可用作话术参考，但通用理解/推理大概率弱于 DeepSeek 大模型——用评测数据说话，避免盲目换底座。

### P2 —— 用数据集做后续微调（远期，需先清许可）

11. **SmileChat（55k，CC0）/ CPsyCounD（3134，CC-BY-4.0）/ SoulChatCorpus（Apache-2.0）/ PsyQA（22k，学术）**：若星图未来要自训垂直小模型，这些是可用的中文共情/咨询语料池；**优先 CC0/CC-BY/Apache 这类可商用许可，排除非商用权重（如 MeChat 权重若为 NC）**。
12. 建议先做「数据质量清洗 + 红线语料（自伤/自杀）人工标注增强」，再谈微调——**现有开源语料几乎没有危机转介的正面样本**。

### 红线合规（务必守住）

13. **危机识别转介必须自研**：开源界无现成「识别 + 12356 转介」方案，只能借鉴 MentalLLaMA/SMHD 的**信号分类** + 星图自建关键词/语义规则 + 安全兜底，绝不能依赖上述模型做干预。
14. **剥离「诊断/治疗」话术**：MentalLLaMA、PsyLLM、PHQ-9/GAD-7 数字化都倾向「下诊断」，与星图「非医疗、非治疗」红线冲突；**只用其信号识别，不用其诊断结论**。特别注意 CLPsych 2026 研究指出开源模型在 PHQ-9/GAD-7 上存在**心理测量学失配（psychometric misalignment）**，小星**不可用 LLM 直接给用户做量表打分/下诊断**，量表只能作为「自查引导」。
15. **规避角色化依赖**：EmoLLM 的「爹系男友/御姐」等角色扮演与「不贴人格标签」相悖，借鉴其工程但**不引入其人格化角色**。
