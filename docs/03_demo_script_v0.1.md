# 「星图」90 秒演示脚本 v0.1

> 目的：90 秒内让面试官记住三件事——①AI 能长期理解一个人（不是聊天）；②状态可视化有信息增量（会演化的星图）；③产品输出可执行路径且闭环（反馈改变星图）。
> 配套功能已落地：星图页顶部的日期 chips（演化回放）。

## 1. 演示前准备清单

- [ ] 7 天真实记录导入完毕（`npm run import`，data 里 days.json 应有 ≥7 天）
- [ ] 引擎模式确认：有 Key 用 LLM，无 Key 用 Mock（两者都能演完，LLM 主题名更自然）
- [ ] 预热页面：提前打开 `/star-map` 和 `/report` 各一次（懒加载完成后演示不卡）
- [ ] 录屏：Windows `Win+G` 或 OBS，1920×1080，60fps，关闭无关通知
- [ ] 点开一个粒子详情卡确认原文引用存在（镜头 2 素材）
- [ ] 掐表排练 2 遍以上（见第 4 节）

## 2. 分镜表（90 秒，逐字稿）

| 时间 | 画面 | 操作 | 旁白（逐字稿） |
|---|---|---|---|
| 0–8s | 星图全景，缓慢拖拽旋转一圈 | 鼠标按住拖拽 | "这是我做的 AI 产品「星图」。它每天和你对话十分钟，把你散落的念头，变成一张看得见的内心地图。粒子是你的念头，颜色是情绪，大小是你提到它的频率。" |
| 8–20s | 点击最大最亮的粒子，右侧详情卡弹出 | 点击粒子 | "比如这颗「转行焦虑」，点开能看到我原话的引用、它的情绪和关联主题。这张图不是我画的——是 AI 从 7 天对话里一句句抽取、归并出来的。" |
| 20–38s | 依次点日期 chips：第 1 天 → 第 3 天 → 最新状态 | 点 3 次 chip | "更关键的是，星图会演化。第 1 天只有 3 个粒子；第 3 天，新念头出现、连线开始生长；7 天后，你能看到自己的状态结构——哪个域在耗能、哪些念头互相喂养。把自我叙事变成可回放的趋势数据，这是星图的信息增量。" |
| 38–55s | 切到报告页，从上到下读 | 点顶部导航"报告" | "基于这张图，AI 给出状态报告：你现在处于「立业期方向摇摆」，根因链分现象、近因、远因三层，最后给一条本周可执行的路——不是鸡汤，是可验证的动作。" |
| 55–70s | 切换逻辑版/结果版按钮 | 点一次切换 | "它还会按你的认知风格分层交付：爱看逻辑的人给推导过程，要结果的人直接给动作。分层在后台暗层判定，用户无感。" |
| 70–85s | 报告页底部点"有帮助"→ 输入原因 → 提交 | 点反馈 | "报告有没有用，你点一下，这条反馈会回写进画像——明天这张图就会变。产品不是给你答案，是和你一起演化。" |
| 85–90s | 切回星图页，定格全景 | 点导航"星图" | "看见自己，才能指路。这就是星图。" |

## 3. 镜头操作要点（防翻车）

1. **镜头 2**：粒子详情卡必须露出"原文引用"——这是"它懂我"的证明，提前确认哪颗粒子引用最好。
2. **镜头 3**：日期 chips 是演化回放的关键，排练时点准节奏（第 1 天 → 中间某天 → 最新），每次点击后等图重绘完再开口。
3. **镜头 4**：报告页提前打开过（懒加载完毕），直接从上往下念，不要滚动太快。
4. **镜头 5**：逻辑版/结果版只切一次，别来回点。
5. **镜头 6**：反馈提交后会有 Toast（"已记下…明天你会看到星图的变化"），念完 Toast 再切页。
6. **备用方案**：现场网络/API 故障 → 切换预录截图 PPT（第 1 天 vs 第 7 天对比图 + 报告截图 + 反馈 Toast 截图），旁白不变。

## 4. 排练安排

- 第 1 遍：对稿走位，不看秒表，找不顺口的词。
- 第 2 遍：掐表，标记超时镜头（超时优先砍旁白，不砍操作）。
- 第 3 遍：正式录屏，检查鼠标轨迹是否晃、页面切换是否有白屏。
- 若投递要求手机竖屏视频：重录竖屏版（960×540 缩放 + 手机框），旁白不变。

## 5. 演完之后的 30 秒（若面试官追问）

- 被问"和聊天机器人有什么区别"→ 答：长期记忆 + 结构化 + 指路闭环，重点是"输出一条路"。
- 被问"星图是不是炫技"→ 答：每条视觉编码都有语义（颜色/大小/亮度/连线/时间），自我报告的趋势数据本身有心理学价值。
- 被问"为什么出生年月"→ 答：文化符号资产的工程化使用（详见求职文档 Q3）。
