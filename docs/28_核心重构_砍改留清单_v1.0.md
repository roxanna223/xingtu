# 「星图」核心重构 · 砍/改/留清单 v1.0

> 性质：以《初心与底色》为唯一参照系，对当前实现（10 页面 / 20 API / 10 套提示词 / 全部功能模块）做一次**本质层面的盘点**。
> 出发点：创始人判断——"目前只是浮于表面的量化修正，真正的关键是把底层逻辑的核心点找到，一切（项目、小星、用户体验）都以它展开"。

## 一、框架：以"一步"为硬通货

### 1.1 核心命题（唯一，剥掉一切语言修饰）

> **星图的全部价值 = 让用户更省力地缩小"现在的我"与"想成为的我"之间的距离。**

推导链（从宪法逐层剥壳）：

| 宪法原话 | 剥壳后 |
|---|---|
| "清晰的量化 + 定制化的方案，让我变得更健康" | 数据不是目的，**变好**才是目的；方案是手段 |
| "看到差距，看到改变、看到通往成功的路" | 差距、改变、路，三者都只在**有目标参照系**时才有意义 |
| "那我们将省下多少力量专注于前行" | 产品被雇佣的唯一任务：**替用户省下找路的力量** |
| "不断前进成为心中的自己" | 终点是"成为"，不是"被记录" |

结论：**不是记录，不是量化，不是陪伴。是缩小差距。其余全是手段。**
"量化"是手段中的手段——它服务于"差距可见"，不服务于"数据好看"。

### 1.2 价值单元：「一步」

唯一定义价值的硬通货 = 用户经历一次完整的最小闭环：

```
看见差距 → 迈出一步 → 感知改变
```

- 一次对话、一份报告、一次记录，只有参与构成"一步"才产生价值；
- 所有功能只分三类：
  - **A 核心**：让"一步"发生得更频繁、更容易；
  - **B 输入**：为"一步"提供原料（采集、画像）；
  - **C 其他**：默认砍或冻结，无例外。

### 1.3 本质三问（对任何功能/提示词/页面/指标）

1. 它让用户**看见差距**了吗？（看见"自己" ≠ 看见差距。**镜子 ≠ 导航**）
2. 它让用户**迈出一步**了吗？（知道 ≠ 走。一句建议 ≠ 一步）
3. 它让用户**感知到改变**了吗？（被记录 ≠ 改变。数据 ≠ 反馈）

**三问全否 → 砍或冻结。无例外。**

### 1.4 语言去魅规则（防被自己的语言迷惑）

- 一切评价必须用**行为句**：`用户做了什么 → 看到/得到什么 → 因此更可能发生什么`；
- 禁用名词包装：姿态、资产、机制、生态、闭环、进化、本能、能量、北极星……这些词**不构成论证**；
- 每个"听起来很深"的词，先翻译成行为再评估。本项目自身的语言陷阱：

| 项目自己的说法 | 行为翻译 | 本质判断 |
|---|---|---|
| "陪伴姿态" | 用户倾诉时小星只回应情绪、不给下一步 | 三问全否 → 不足以支撑价值（需补"照见+给步"，见 R3） |
| "进化层 / 个人资产" | 下次聊天时小星可能引用用户说过的话 | 方向对（服务看清"人"），但当前是暗层标签堆叠，不是人的模型（见 R5/R9） |
| "北极星：每周回顾→行动→复看循环" | 用户每周打开报告、点"已做" | 度量的是**行为频率**，不是**差距缩小**；可用推送达成，不度量价值（见 R7） |
| "量化"（主页） | 心力/能量/星光 = 记录天数 × 系数 | **假量化**（代码注释自认"纯视觉"），砍（C1） |
| "三坐标（目标/自我/差距）" | 报告里的三个字段，其中"差距"可空 | 方向对，但"差距"被做成了可空字段，而它应是主角（见 R4） |

**铁律：一个功能如果只能靠抽象名词解释自己的价值，就视为没有价值。**

### 1.5 一条硬规则

任何新东西上桌之前先回答两问：

1. 它在价值链的哪一环？（看清 / 差距 / 路 / 引领 / 改变）
2. 它让一个**真实用户**今天多走了一步吗？

答不出 → 不做。不是"以后再做"，是"不做，直到真实闭环跑通"。

## 三、改清单（朝核心重构，含具体方向）

### R1 主页：从"仪表盘"改为"今天的一步"

- 现状：假状态条 + 入口列表。
- 方向：主页只回答三件事——**我现在在哪**（真实、一句话）→ **我和想成为的我差什么**（今天的一步）→ **这一步我走了吗**。用真实数据：昨日差距、进行中目标的最小一步、情绪轨迹。
- 这是 Q3"主页真实化"的正确含义：不是"把假数字换成真数字"，而是"把数字换成差距 + 一步"。
- 第一动作：删 C1 状态条，主页 Hero 区改为"今天的一步"卡片。

### R2 目标系统：从"打卡游戏"改回"差距地图"

- 现状：拆解 → 积分打卡 → 彩蛋升级。
- 方向：**目标是量化的参照系**（没有目标，量化只是镜子）。每个步骤绑定"这一步让我离目标近了什么"；完成/未完成必须回写主题极性；星图/报告围绕目标展示差距与进度。
- 验收（总策划 P2 原句）：≥1 位用户能说"它让我看到了差距"。
- 第一动作：删 C2 游戏层；步骤卡上的 ⭐ 分换成"离目标还有多远"。

### R3 小星：停止两极摇摆，建立**引领模型（四拍）**

- 现状：先被做成任务执行器（首轮必带目标提醒+彩蛋），后被纠正成"永远跟随话题、建议是报告阶段的事"——**两个极端都没有"引领"**。初心场景"迷茫时找小星"的用户，得到的只有倾听（09 评审原话）。
- 方向：**陪伴是姿态，引领是本职。** 四拍节奏：
  1. **接住**——情绪承接，不评判；
  2. **照见**——把他说的映照成可识别的处境/模式（"这件事你已经熬到第三周了"）；
  3. **给一步**——只在他被卡住/开口要时，给当下能走的最小一步（他可控、明天就能做）；
  4. **陪走**——记住这一步，下次自然问起。
- 必须删除：`chatMessages` 与 `starMessages` 中"建议是报告阶段的事"——指路必须回到**迷茫的第一现场**。
- 验收：一个真实用户在迷茫的对话当下，拿到了"明天就能做的一小步"，而不是只得到倾听。

### R4 报告：把"差距"从可空字段改为报告的核心输出

- 现状：gap 兜底文案"今天还看不出明显差距"（用户 A："觉得没收获"）；报告 = 回放 + 观察 + 一句话建议。
- 方向：报告第一句回答"你和想要的差什么 / 近了什么"。**没有目标时，报告的核心动作是帮用户把模糊的"想成为"说出第一版**（差距的种子），而不是免责声明。三坐标里"差距"永远是主角。
- 第一动作：改 `reportMessages` 提示词——coordinates.gap 空值时不再输出"看不出差距"，改为"今天还没说清想要什么，我们先把'想成为'说出一句"。

### R5 画像/抽取：从"事件账本"升级为"人的模型"（价值层画像提到 P0）

- 现状：抽取主题/情绪/极性（事件碎片）；价值层 ❌；"我是谁"文档里装的是星座/人生任务/主题名（`lib/evolution.js`）。
- 方向：新增**价值层抽取**——在意什么 / 回避什么 / 反复的模式 / 什么让他有能量 / 他嘴上说想成为什么。这是宪法第三层"认识我自己"的落地。
- 状态层（主题/情绪）**降级为原材料**，不再被称为"画像"本身。
- 验收：从 7 天真实记录里能说出一条"这个人在意什么、想成为什么"且用户认可。

### R6 报告生成时机：当天即时，不等次日 6:00

- 现状：6:00 划日 + 懒生成，用户当天打开看到"生成中"10+ 秒（观察项 O5）。
- 方向：日记保存/对话结束后**即时生成当天小结**（轻量版）；6:00 完整日报保留为"昨日归档"。用户走完一步，立刻能看到一步。

### R7 北极星指标：从"行为频率"改为"价值频率"

- 现状："每周完成一次回顾→行动→复看循环的比例"——度量打开率+点击率，可被推送达成，不度量价值。
- 方向：北极星 = **"用户每周至少经历一次『看见差距 + 迈出一步 + 感知改变』的比例"**；过程指标 = 每步之后的"改变可感"确认率。
- 硬条件：必须用真实用户数据计算——**创始人 7 天真实记录是门槛**（已拖延 6 天）。

### R8 梳理卡：减负

- 现状：summary + 3 moments + signals + unsaid + tomorrow（用户 A：编辑负担重，多数直接存）。
- 方向：只产出"一句话 summary + 今天最想改变的一件事"，其余字段删除或折叠。

### R9 进化层：去包装，并入画像

- 现状：instinct 置信度（±0.05/−0.1）+ persona 三文档 + ≤800 字注入；设置页裸展示文档，用户不知道是什么（用户 A）。
- 方向：语言去魅——它做的事只有一件："**下次聊天时小星更懂他**"。把它并入 R5 的价值层画像，作为"相处要点"子集；删除"进化/本能/资产"包装语言；设置页的裸文档换成一句人话："小星记得你 X、Y、Z——不想要可以删"。

## 六、落地顺序（前两周）

**第 1 周（先砍，把面收干净）：**
1. C1+C2+C3+C4 全部执行（假数值、游戏层、3D 入口、星座/cohort）；
2. R1 主页改为"今天的一步"（真实数据版）；
3. 创始人开始 7 天真实记录（一切后续验证的前提）。

**第 2 周（重建链条）：**
4. R3 小星引领模型四拍（改提示词 + 删"建议是报告阶段的事"，用一个真实场景走 5 轮验证）；
5. R4 报告差距核心化 + R6 当天即时小结；
6. R5 价值层抽取第一版（用 7 天真实记录验证：它能不能说出"用户在意什么、想成为什么"）。

**唯一验收标准**：第 2 周末，创始人本人能指着产品说出一句——**"它让我看到了差距，并告诉我今天该走哪一步。"**
说得出 → 继续；说不出 → 回头修四拍与差距，**不进入任何新功能**。
