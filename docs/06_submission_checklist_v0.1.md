## 2. 演示速启（3 条命令）

```
cd star-map
npm install
npm run import ../data/演示数据-7天日记.md   # 兜底数据；有真实记录则换成 ../data/我的7天记录.md
npm run dev                                  # 打开 http://localhost:3000
```

- 有 API Key：先 `copy .env.example .env` 填 `DEEPSEEK_API_KEY`，再 `npm run eval` 看 LLM 评测是否双达标。
- 无 Key：Mock 模式同样能演完全程（星图主题名是"域·关键词"格式，若介意可在面试中一句带过"演示环境未接 Key，引擎自动降级"）。
