# 产品方向调整纪要 v1.0（2026-08-29）

> 性质：记录本轮创始人方向决策，作为后续设计与开发的上游输入。
> 相关调研：`16_ECC自我进化调研_v1.0.md`、`17_日记类产品调研_v1.0.md`。
> 状态：决策已定，方案待调研合并后细化。

---

## 1. 「记录」模块拆分为「日记」模块（决策）

- 不再判定"今天是否已记录"（取消 covered/已保存 这类状态对体验的约束）。
- 手动记录 → 改为独立 **「日记」模块**：用户手动记录的每日归档，支持自我梳理，类似写文档。
- **日报的来源 = 手动日记 + 和小星的对话**，二者共同归纳。
- 日记**不强制**：不写也能正常使用产品。
- 现有表单式记录方式体验不佳，需要"更方便的记录方式"→ 已产出《日记类产品深度调研报告》（`docs/17_日记类产品调研_v1.0.md`），该板块后续**重新设计**。

## 2. 小星 = 自我进化的智能体（决策）

- 和小星的对话**不限制流程**：把小星封装为一个智能体——「小星」。
- 能力面：测验、目标分析梳理拆解、个人定位等，类似**人生导师**。
- **初始提示词每个账户一致**；随用户使用，慢慢沉淀出独属于该用户的**自我进化提示词**。
- 进化提示词 = **该账户用户的个人资产数据**，保存在对应账户的数据库。
- 实现参考：GitHub 开源项目 [affaan-m/ECC](https://github.com/affaan-m/ECC) 的自我迭代机制 → 已产出《ECC 自我进化体系深度调研》（`docs/16_ECC自我进化调研_v1.0.md`），源码位于 `参考项目资源/ECC-main/`。

## 3. 日报与成长坐标系（决策）

- 聊天方案参考 ECC 调研结论再定（见第 2 条）。
- **日报 = 和小星的对话 + 用户自我记录（日记）的归纳**。
- 一切以**用户实际情况为中心坐标**，建立「**目标 / 自我 / 差距**」三方向坐标体系，生成成长规划。
- **日报固定在次日 6:00 刷新**：以每日 6:00 为日报刷新点，总结过去一整天的对话内容（6:00 划日，即 6:00 前的"深夜"归前一天）。

## 4. 记录页改造顺序（决策）

- 记录页内容**先看 ECC 调研报告（第 2 条）后再做决定**——当前不直接动记录页。
