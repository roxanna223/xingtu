# 日记类产品深度调研报告 v1.0

> 项目：星图（AI 自我状态导航产品，Next.js，面向 20–35 岁人生转折期人群）
> 背景：将「快速记录表单」改造成独立「日记」模块。定位 = 用户手动记录的每日归档 + 自我梳理，自由写作，**不强制**。
> 核心痛点：**手动记录需要更方便的记录方式**——回答「怎样的记录方式让人愿意每天花 5–10 分钟写」。
> 调研方法：web_search 中英文多轮检索（官方站点、App Store/Google Play 页面、产品博客、媒体评测、帮助中心）。
> 更新：2026-08（调研覆盖 18 个产品，重点深挖 10 个）。

## 2. 关键发现

### 2.1 记录入口与快速记录方式

**结论：愿意天天写的前提是「从想记到开写 ≤ 1 次点击 / 1 句命令」。**

- **Day One（入口最全的标杆）**：提供 iOS 主屏/锁屏小组件（widget）、Siri 快捷指令（Shortcuts）、分享扩展（Share Extension，从相册/网页/任意 App 一键导出成日记）、Apple Watch、Mac 菜单栏、以及「Today」小组件——打开即是当天草稿，无需选日期、无需起标题。参见 [Day One widgets for iOS](https://dayoneapp.com/guides/tips-and-tutorials/day-one-widgets-for-ios/)、[How to Capture Almost Anything into a Day One Entry](https://thesweetsetup.com/capture-almost-anything-into-day-one/)。
- **Apple Journal**：支持**锁屏小组件**一键新建，「建议时刻（Moments/Suggestions）」在主页生成一排可点卡片（照片、去过的地方、听过的歌、训练记录、播客），点卡片即以该素材为锚点开写；还提供**反思提示（Reflection Prompts）**。参见 [Apple newsroom 发布稿](https://www.apple.com/ng/newsroom/2023/12/apple-launches-journal-app-a-new-app-for-reflecting-on-everyday-moments/)、[9to5Mac](https://9to5mac.com/2023/12/11/ios-17-2-includes-all-new-journal-app-heres-how-it-works/)。
- **flomo**：把「快速记录」做成核心——无标题、无分类压力，输入框即卡片；官方明确「快速记录」作为基础功能单列帮助页。参见 [flomo 快速记录](https://help.flomoapp.com/basic/quick-input.html)。
- **心光**：主打**语音入口**——说一段话，AI 自动转写并整理成结构化条目（时间轴 + 心情 + 标签），把「写」降为「说」。参见 [心光 App Store](https://apps.apple.com/cn/app/%E5%BF%83%E5%85%89-ai-%E7%94%9F%E6%B4%BB%E8%AE%B0%E5%BD%95%E4%BC%B4%E4%BE%A3/id1631169735)。

### 2.2 输入形态（从重到轻的谱系）

| 形态 | 代表产品 | 交互细节 |
|---|---|---|
| 纯自由文字 | Day One / 一本日记 | 富文本正文 + 可选附件 |
| 语音转写 | 心光 / Day One / Rosebud | 语音 → 文字 +（心光）AI 整理 |
| 拍照 + 一句话 | Day One / Apple Journal | 照片为锚，配短文字，元数据自动带 |
| 模板/格子 | 格志 / Day One 模板 | 预置问题格子，逐格填空 |
| 提问引导 | Apple Journal / Stoic / Day One Prompt Packs | 每天一个问题，答完即一篇 |
| 纯点选 | Daylio | 点心情图标 + 勾活动标签，文字可选 |

**关键洞察**：输入形态决定「5–10 分钟」能不能成立。Daylio 的纯点选 10 秒完成，是「最低摩擦」极端；Day One/Apple Journal 用「素材锚点 + 一句话」把中等篇幅写作也压到 5 分钟内；心光用语音把「写」换成「说」。

### 2.3 降低写作压力的机制（针对「空白页焦虑」）

- **格志 Grid Diary：把日记变成「填空题」**——九宫格模板每个格子一个预设问题（如「今天最开心的事」「想改进的事」），用户逐格作答，天然消除「不知道写什么」。媒体称其帮助用户「每日三省吾身」。参见 [猎云网格志报道](https://lieyunpro.com/archives/121699)、[格志体验笔记](https://www.360kuai.com/94a6f065667ee3a81)。
- **每天一个问题（Prompt of the Day）**：Day One 的 Prompt Packs（预设问题包，2024 起推送，Android + Labs）、Apple Journal 的反思提示、Stoic 的晨间/晚间提问——把「自由写作」变成「回答一个具体问题」，字数门槛天然降低。参见 [Day One Prompt Packs](https://dayoneapp.com/releases/prompt-packs-new-labs-android/)。
- **flomo：输入摩擦最小化**——无标题、无排版、无分类，卡片即写即走；「用自己的话写卡片」是官方方法论的核心理念，弱化「日记」的郑重感。参见 [flomo 用卡片](https://help.flomoapp.com/method/use-card.html)。
- **素材反推（冷启动锚点）**：Apple Journal 的「建议时刻」——不是让用户凭空回忆，而是把当天已有的照片/位置/音乐/训练/播客变成可点入口，「对着一张照片写一句」比「对白纸写一篇」容易得多。
- **AI 续写/追问**：Rosebud 在用户写完一段后，AI 顺着内容**追问**（follow-up）、做「镜像（mirror）」反馈，让「写了开头写不下去」的人能继续。

### 2.4 组织与回顾

- **时间维度**：日历视图（Day One / Diarly / Journey）、时间轴（心光）、地图视图（Day One / Journey，按地点聚合）。
- **「那年今日 / On This Day」**：Day One、一本日记的核心回顾功能——每天推送「去年/往年今日」的旧条目，是日记类产品最强的「复看」钩子。
- **标签/关键词**：flomo 的标签体系（卡片打标签后可按主题聚合）、心光 AI 自动打标签、Day One 标签 + 搜索。
- **flomo 每日回顾（Daily Review）**：每天随机回放若干历史卡片，做「温故」；另有「随机漫步」在卡片间建立联想。参见 [flomo 每日回顾](https://help.flomoapp.com/method/use-review.html)。

### 2.5 激励留存

- **连续天数（Streak）**：Day One、Daylio、一本日记、Journey 通用。Daylio 尤其突出——点选完成即算一次，打卡成本极低，连续天数可视化强化「不断更」。
- **每日提醒（Reminder）**：几乎所有产品都有；Day One/Stoic 可设多时段（晨间提问/晚间复盘）提醒。
- **补写（Backfill）**：Day One、一本日记允许补记历史日期，不因「漏了一天」而破功。
- **成就/里程碑**：Daylio 有连续打卡成就；一本日记/格志以「日历变密」本身作为成就暗示。
- **回顾推送（复看即激励）**：Day One 的 On This Day、flomo 的每日回顾，用「过去的内容」制造「继续写下去」的理由——星图已有「日报 6:00 刷新」天然契合此机制。

### 2.6 AI 能力（结构化程度 / 可摘要性重点）

| 产品 | AI 能力 | 对「可结构化/可摘要」的启示 |
|---|---|---|
| 心光 | 语音转写 + 自动整理成时间轴/心情/标签；自动回顾总结 | 用户随便说，AI 负责把「自由流」变成「结构化条目」 |
| Rosebud | 记录后追问、AI 镜像、识别思维/情绪模式、洞察 | AI 主动「把话问下去」，产出可摘要的反思片段 |
| Mindsera | 结构化框架（CBT/感恩/成长模板）+ AI Mentor 人格 + 情绪/主题分析 | 框架本身即半结构化，AI 在框架内做摘要与反馈 |
| Reflect | 每日笔记 + 反向链接 + AI 摘要 | 自由写作仍可被 AI 摘要归并 |
| Me.bot | 记忆用户内容、主动回顾/提醒、与聊天融合 | 「日记 + 对话」同源存储，AI 统一记忆 |
| flomo（新） | AI 语音备忘、回顾洞察 | 卡片流也能被 AI 归纳 |
| Apple Journal | 设备端反思提示/建议（轻 AI，本地） | 用设备上下文生成可写锚点 |

**核心结论（与星图强相关）**：日记的「可结构化程度」并非只能靠强制模板获得——**心光、Reflect、Rosebud 证明「自由写 + AI 事后结构化」可行**；而 Daylio/格志证明「轻点选/轻格子」可在输入端就半结构化。两条路线都通向「日记内容可被汇总/摘要」这一目标，星图可结合。

## 4. 值得抄的设计模式 Top N

### 模式 1：Day One 的「多入口快速记录」——消灭「开写前的路程」
- **解决什么摩擦**：用户不写日记，一半是因为「打开 App → 新建 → 选日期 → 起标题」这段路程在念头转瞬即逝时太长。
- **具体机制**：小组件/锁屏组件一键直达当天草稿、Siri 快捷指令、分享扩展、打开即当日。
- **对星图的启示**：日记入口要做成「主页常驻一键 + 打开即当日空白页，无标题、无日期选择」。Next.js Web 端可做「下拉快速记录条」（主页顶部永远有一个输入框），移动端后续再做快捷指令/小组件。**当天有草稿就自动续写，没有就开空白**——与星图「每日归档」语义一致。

### 模式 2：Apple Journal 的「建议时刻（Moments）」——用已有素材反推记录
- **解决什么摩擦**：空白页焦虑 + 想不起今天发生过什么。
- **具体机制**：把照片/位置/音乐/训练/播客变成一排可点卡片，点卡即以该素材为锚点开写；另有反思提示兜底。
- **对星图的启示**：星图手里**已有大量用户数据**（记录/对话/情绪序列/星图节点）。日记入口旁可放「今天的小星对话说了什么」「今天记录过的情绪/主题」作为**可点锚点**——「接着昨晚聊的事写一句」远比「写一篇日记」容易，且天然让日记与 AI 对话/画像打通。注意：锚点只作提示，**不预填、不替写**。

### 模式 3：flomo 的「卡片式 + 输入摩擦最小化」——把郑重感降到最低
- **解决什么摩擦**：日记的「郑重感/仪式感」反而成了心理负担（怕写不好、怕不长）。
- **具体机制**：无标题、无排版、无分类，一张卡片即写即走；「用自己的话写卡片」。
- **对星图的启示**：日记模块**默认形态 = 单卡片自由流**，不要求标题、不要求长度、不要求分类。用户可以只写一句话（或拍一张图 + 一句话）。这直接呼应星图「不强制、自由写作」的定位。

### 模式 4：格志 Grid Diary 的「格子/填空题」——结构化但不压迫
- **解决什么摩擦**：结构化模板能消除「不知道写什么」，但固定强制模板又会劝退自由表达者。
- **具体机制**：九宫格每个格子一个预设问题，逐格作答；格子可自定义/可跳过。
- **对星图的启示**：提供**可选**的「今日格子模板」（如：今天的关键事件 / 情绪 / 一件想继续的事），但**必须可跳过、可关、可自由切回空白流**。星图已有「收束三问」的资产，可把三问做成日记里的**可选收尾引导**，而非必填。引导要轻：默认自由流，引导只在「卡住时」出现。

### 模式 5：Day One / Apple Journal / Stoic 的「每天一个问题」——轻引导，不制造压力
- **解决什么摩擦**：自由写作对「不知道写什么」的人是负担；但长篇模板又是另一种负担。
- **具体机制**：每天给**一个**具体问题（Day One Prompt Packs、Apple Journal 反思提示、Stoic 晨/晚提问），答完即一篇，问题可换/可忽略。
- **对星图的启示**：日记页顶部给**一句可选问题**（如「今天哪一刻让你感觉不错？」），用户可直接答、可换一个、可无视直接写。问题池可与星图画像联动（针对用户近期高频主题出题），但**永远可跳过**——符合「引导轻、不强制结构化、不制造压力」的要求。

### 模式 6：Daylio 的「点选式」——把输入成本压到 10 秒
- **解决什么摩擦**：连一句话都不愿打字的用户；以及需要结构化数据的系统。
- **具体机制**：点心情图标（5 级）+ 勾活动标签，文字可选；完成即打卡计 streak。
- **对星图的启示**：日记里增加**可选的情绪点选（心情色）**，一行点选即可存档，文字成为可选。这对星图有双重价值：① 降低最低输入成本；② 情绪点选是**天然结构化字段**，直接喂给 6:00 日报和情绪时间序列，提升可摘要性。星图已有「心情色/情绪序列」概念，日记点选可与之无缝对接。

### 模式 7：Day One / 一本日记 的「那年今日（On This Day）」——复看即留存
- **解决什么摩擦**：写完就忘，没有「回来看」的理由，于是失去「继续写」的动力。
- **具体机制**：每天推送历史同日旧条目，制造「时光胶囊」的惊喜感。
- **对星图的启示**：星图已有日报/星图回放，日记可增加「那年今日/上周此时」的轻回顾位；更关键的是——**日记内容要进入星图的「复看」闭环**（日报引用、星图回放、周期报告引用原话），让「写日记」和「看到成长」之间形成因果，这才是长期留存的根。

### 模式 8：心光 / Rosebud 的「语音 + AI 整理 / 追问」——把「写」降为「说」，把「卡住」变成「对话」
- **解决什么摩擦**：打字慢、不想组织语言；写一半写不下去。
- **具体机制**：心光语音转写后 AI 自动整理成时间轴/心情/标签；Rosebud 在用户写完一段后 AI 顺着追问、做镜像反馈。
- **对星图的启示**：日记模块应内置**语音转写**（星图已有语音依赖 Chrome/Edge 的基础，可扩展）；写入后可由小星做**轻量追问/收束**（把「写日记」平滑衔接进「与小星对话」），但**追问必须可关**，避免把自由写作变成被审问。追问产出的内容直接进入画像与日报摘要。

### 模式 9：Mindsera 的「框架 + AI Mentor」——重度用户的进阶选项
- **解决什么摩擦**：想认真梳理、有明确议题（焦虑/决策/目标）的用户需要更深的结构与反馈。
- **具体机制**：结构化框架（CBT、感恩、成长等）+ AI 人格化反馈 + 情绪/主题分析。
- **对星图的启示**：作为**可选进阶层**（不做默认）。当用户在日记里写「很焦虑 / 不知道该不该…」时，星图可提供「是否进入引导梳理」的可选项，由小星用已有画像做结构化追问。这契合星图「指路/陪走」的定位，但要**用户主动触发**，不制造「被分析」的不适。

## 5. 对星图「日记」模块的结论性建议

### 5.1 入口设计（回答「怎么让人愿意点开」）
1. **主页常驻「今天」入口 + 下拉快速记录条**：主页顶部放一个永驻输入框（flomo 式），点开即当天日记草稿，**无标题、无日期选择、无必填**；当天有草稿则续写。
2. **打开即当天**：与星图「每日归档」语义对齐——日记 = 今天的空白页/续写页，不做「新建文档」心智。
3. **与对话/画像打通的「锚点入口」**：日记入口旁显示可点锚点——「昨晚与小星聊到的事」「今天的情绪」「一个进行中的目标」，点了就以它为起笔（Apple Journal 模式）。锚点只提示、不预填。
4. 移动端后续：快捷指令/小组件/分享扩展（Web 端先做下拉条 + 常驻入口）。

### 5.2 最低摩擦的记录形态
- **默认 = 单卡片自由流**：一句话、一段话、一张图+一句话、一段语音，都算一次有效记录（Day One 的「拍照+一句话」+ flomo 的「无压力卡片」）。
- **语音转写**为第二输入通道（心光模式），星图已有语音基础，扩展为「说一段 → 转写 → 可再编辑」。
- **可选情绪点选**（心情色一行点选）：把最低成本压到 10 秒（Daylio 模式），同时产出结构化字段喂给日报/情绪序列。
- **不设字数门槛、不设完成标准**：写一个字也算记录，贯彻「不强制、不制造压力」。

### 5.3 可选的模板/引导（要轻、不强制、不制造压力）
- **「今日一问」可选问题**：顶部一句可跳过的问题，可换、可无视（Day One/Apple Journal 模式）；问题池与画像联动但永远可跳过。
- **「格子模板」可选**：把星图已有的「收束三问」做成日记末尾的**可选收尾引导**（格志模式），可跳过、可关、可切自由流。
- **AI 追问可选**：写完一段后可出现小星的轻量追问/收束（Rosebud 模式），**可一键关闭**；把「写日记」平滑衔接进「与小星对话」，但不把自由写作变成被审问。
- **原则**：引导是「卡住时的扶手」，不是「必填的表格」。任何结构化都不做默认强制。

### 5.4 与 6:00 日报汇总的衔接点
- **日记 = 日报的「我的版本」**：日报是 AI 视角的「过去一整天总结」，日记是用户**主动写下的第一人称陈述**。日报应**引用日记原话**（星图原则「观察必引用原话」），让用户看到「我写的」和「AI 总结的」互相印证。
- **结构化字段提升可摘要性**：情绪点选、可选标签、今日一问的作答，都是**天然结构化锚点**，日报可直接消费（无需从自由文本强抽）。自由文本部分则由现有「抽取」提示词处理——心光/Reflect 已证明「自由写 + AI 事后结构化」可行。
- **时间语义**：日记按「自然日」归档，与日报的 6:00 刷新边界（过去一整天）对齐；6:00 后新写的内容归入下一个自然日，避免边界歧义。
- **闭环复看**：日报/周报/星图回放中引用日记片段 → 用户看到「写日记 → 出现在报告/星图里 → 看见成长」的因果，这是日记留存与「复看」闭环的接榫点（呼应北极星指标「回顾→行动→复看」）。

### 5.5 一句话定位（供产品内部对齐）
> 星图「日记」= **一张永远打开的当天卡片**：可自由写、可说、可点情绪、可拍一张照片配一句话；卡住了有「今日一问」扶手、写完了有小星轻收尾；每晚 6:00 它和小星对话一起，被汇总成「你今天」的日报。
