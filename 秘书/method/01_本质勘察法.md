# 「秘书」方法层 01 · 本质勘察法（接入任何项目的勘察 SOP）

> 目的：把一个陌生项目快速读透——**本质、框架、结构、状态、核心**——并产出可执行的四件套。
> 使用时机：接入新项目时（流程见 `06_接入手册.md`）。快速版约 60 分钟，深潜版视项目规模。
> 铁律：勘察只看事实与原文；**拿不到"原话"，本质无从谈起**（见 `06` §四）。

## 一、勘察目标与产出

| 要理清的 | 产出物 | 落到 |
|---|---|---|
| 本质 | 核心命题一句话 + 初心链 | 实例 `00_核心锚点.md` §一、§二 |
| 框架 | 价值单元 + 本质三问（定制版）+ 语言去魅 + 硬规则 | 实例 `00_核心锚点.md` §三 |
| 结构 | 结构地图：模块 × 价值链环节 × 状态 | 实例 `00_核心锚点.md` §三 |
| 状态 | 链条完成度 + 一句话状态诊断 + 砍/改/留/冻结 | 实例 `00` §四 + `02_任务追踪器.md` |
| 核心 | 枢纽环判断 + 任务队列第一步 | 实例 `02_任务追踪器.md` |

## 二、勘察六步

### 第 1 步 收集原料（只看事实，分三类记录，不混）

- **原话**：创始人/发起人口述、初心文档原文——逐字摘存，这是防漂移的锚；
- **行为**：项目实际做了什么——读代码、走流程、看真实用户/客户反馈；
- **自称**：项目文档如何描述自己——这些是要被"去魅"的对象，不是论据。

### 第 2 步 剥壳（去表象、去语言）

- 每个功能/模块/指标写成行为句：`用户做了什么 → 得到什么 → 因此更可能发生什么`；
- 把"姿态/资产/机制/生态/闭环/进化/本能/北极星/赋能"等名词翻译成行为；
- 三分法：**目的 / 手段 / 装饰**（装饰 = 过不了本质三问）。

### 第 3 步 找链（底层逻辑）

- 从原话抽四件事：**起点痛点 → 用户目的 → 价值链条 → 终点状态**；
- 价值链条通用骨架（项目可以缺环，但按此归位）：
  `感知（看清现状）→ 对照（看见与目标的差距）→ 路径（拿到下一步）→ 推进（被引领着走）→ 结果（改变/达成被感知）`
- 产出三样：
  1. **核心命题一句话**：`[项目]的全部价值 = 让[用户]更省力地[动词][目的]`；
  2. **价值单元**：用户经历一次的最小价值闭环（例：星图 = 看见差距 → 迈出一步 → 感知改变）；
  3. **枢纽环**：链条的断点或价值兑现点（例：星图 = "差距"）。

### 第 4 步 定制三问

- 通用模板：① 它让用户**更接近目的**了吗？② 它让用户**行动**了吗？③ 它让用户**感知到结果**了吗？
- 用项目自己的语言实例化（星图版：① 看见差距了吗？② 迈出一步了吗？③ 感知改变了吗？）；
- 通用附加判断（防偷换）：看见自己 ≠ 看见差距；知道 ≠ 走；被记录 ≠ 改变。
- **三问全否 → 砍或冻结，无例外。**

### 第 5 步 结构盘点与状态诊断

- 每个模块挂到价值链的环上 → 结构地图；
- 每个模块过三问 → 四处置：**砍**（三问全否且是装饰）/ **改**（方向对、形态错）/ **留**（直接服务链条）/ **冻结**（现在不需要、以后可能要）；
- 状态诊断三件：每环完成度（% + 证据）；一句话诊断（例：星图 = "复盘型工具，链条断在'引领'"）；表面功夫清单（自称很强、三问全否的部分）。

### 第 6 步 输出四件套（按 `03~05` 模板实例化）

- 实例 `00_核心锚点.md`：锚点卡（一屏）+ 原文摘存 + 框架 + 语言陷阱表；
- 实例 `02_任务追踪器.md`：任务队列 T1~Tn（砍→改顺序）+ 唯一验收标准 + 基线记录；
- 实例 `03_偏差日志.md`：基线记录；
- 在 `projects/README.md` 登记表登记一行。

## 三、验收（勘察做完了吗）

项目主理人（创始人）能回答两问：

1. "它说出的核心命题与初心链，我认" —— 本质、框架、核心；
2. "任务队列的第一步，明天就能动手" —— 结构、状态。

两问都过 → 勘察完成；不过 → 回第 1/3 步重来，**不进入执行**。

## 四、快速版（时间不够时的最短路径）

读原话（第 1 步只做"原话"类）→ 找链（第 3 步）→ 定制三问（第 4 步）→ 状态诊断只做"一句话诊断 + 任务队列前 3 项" → 输出精简四件套。
深潜版（结构地图 / 语言陷阱表 / 全量砍改留）在项目要动大手术前补做。
