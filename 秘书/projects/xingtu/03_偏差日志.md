# 「星图」偏差日志（只追加）

> 用法：出现偏差时按模板记一条；不修改历史（写错就新增"更正"记录）。
> 升级规则：**同一类型偏差 ≥3 次 → 提案修改框架（`00_核心锚点.md`），而不是继续靠自觉。**

## 模板

```
- [日期] [步骤] 偏差类型（记忆 / 判断 / 语言 / 执行）
  - 现象（行为句）：实际做了什么、与锚点的差异
  - 原因：为什么会偏
  - 回锚动作：读了什么、改了什么、重做了什么
  - 结果：回锚后是否通过三问
```
