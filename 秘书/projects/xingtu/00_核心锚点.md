# 「星图」核心锚点（不可变本质）

> 性质：星图项目"最开始最基础的核心内容"的固化。任何执行、任何改动，先对照本文件。
> 修改规则：本文件只在两种情况下可改——① 宪法《初心与底色》原文被修订（跟随）；② 同类偏差出现 ≥3 次且走完提案流程（见 `03_偏差日志.md`）。**执行任务时禁止顺手改。**

---

## 一、锚点卡（开工前必读，一屏）

1. **核心命题（一句话）**：星图的全部价值 = 让用户更省力地缩小"现在的我"与"想成为的我"之间的距离。
2. **初心链**：量化 → 清晰 → 差距 → 路 → 引领 → **成为心中的自己**。（量化是手段，清晰是桥梁，**差距是枢纽**，成为是终点。）
3. **价值单元「一步」**：看见差距 → 迈出一步 → 感知改变。产品的一切工作只分三类：让"一步"更易发生 / 为"一步"供原料 / 其他（默认砍或冻结）。
4. **本质三问**（一切功能/提示词/页面/指标都要过）：
   ① 让用户**看见差距**了吗？（看见自己 ≠ 看见差距；**镜子 ≠ 导航**）
   ② 让用户**迈出一步**了吗？（知道 ≠ 走；一句建议 ≠ 一步）
   ③ 让用户**感知改变**了吗？（被记录 ≠ 改变；数据 ≠ 反馈）
   **三问全否 → 砍或冻结，无例外。**
5. **语言去魅铁律**：评价一切只用行为句——`用户做了什么 → 得到什么 → 因此更可能发生什么`；"姿态 / 资产 / 机制 / 生态 / 闭环 / 进化 / 本能 / 北极星"等名词不构成论证；**只能靠抽象名词解释价值的东西 = 没有价值。**
6. **北极星指标**：用户每周至少经历一次"看见差距 + 迈出一步 + 感知改变"的比例（必须用真实用户数据计算）。
7. **红线（永不）**：八字/命理排盘与吉凶预测；贩卖焦虑；医疗/治疗承诺；打分定罪；娱乐化量化（积分/等级/彩蛋）。危机信号 → 转介 12356。
8. **助手姿态**：帮人看清、看清差距、对齐目标、一步一步引领；不评判、不贩卖焦虑、不替人做决定。
9. **底色**：形式可以变，初心不能变。

## 二、初心原文（宪法第七节原文摘存，防蒸馏漂移）

> 任何结构化表述与以下原文有出入时，以原文为准。

1. "……我感觉我需要一个对我自己的健康的清晰的量化，且通过这个清晰的量化对我自己做出定制化的方案，让我变得更健康（这是我当前的目的）。"
2. "……在我的事业上，我也需要有这样的量化和分析，我需要让一些都变得清晰，才能看到差距，看到改变、看到通往成功的路；同理，在心理层面也如此，想要保障好的心态，其实与身体健康、环境压力、作息等等等等都有着密不可分的关系；财富自然也是了……"
3. "……这就是我在不断找到自己的一个过程，可以又事业、健康、财富等等外在因素体现，但也必须包含我自己，我是一个什么样的人，我怎么样获得快乐，我人生的意义是什么……这些问题又和我的心理、成长有关，其中也不乏中国优秀的道家文化，像八字这样的对自我的深入了解的'玄学'……"
4. "……不断量化自我，对齐目标（目标若是有人能帮我们看清，看清自己，看清差距，一步一步引领我们前进，那我们将省下多少力量专注于前行！），不断前进成为心中的自己，可以为了理想、对自我的探索，也可以为了成功、财富（同时还希望能顾及身心健康）。"
5. "……无论是为了什么，我想大部分人都想变得更好，只是他们需要一个助手来帮他们完成这些事情。这就是我的初衷，我希望这个项目能一直秉承着做这样的初心，以此为底色。"
6. "……无论这个项目以何种形式呈现，我都希望它能保持初心。"

## 三、框架（核心命题的推导与使用）

### 3.1 推导链（从宪法逐层剥壳）

| 宪法原话 | 剥壳后 |
|---|---|
| "清晰的量化 + 定制化的方案，让我变得更健康" | 数据不是目的，**变好**才是；方案是手段 |
| "看到差距，看到改变、看到通往成功的路" | 差距/改变/路只在**有目标参照系**时才有意义 |
| "那我们将省下多少力量专注于前行" | 产品被雇佣的唯一任务：**替用户省下找路的力量** |
| "不断前进成为心中的自己" | 终点是"成为"，不是"被记录" |

结论：**不是记录，不是量化，不是陪伴。是缩小差距。其余全是手段。**

### 3.2 项目自身的语言陷阱（已核实，防复发）

| 项目说法 | 行为翻译 | 本质判断 |
|---|---|---|
| "陪伴姿态" | 倾诉时只回应情绪、不给下一步 | 三问全否 → 已定 R3 四拍重构 |
| "进化层 / 个人资产" | 下次聊天可能引用用户说过的话 | 方向对，但当前是星座/人生任务/主题名的标签堆叠 → 已定 R9 并入价值层画像 |
| "北极星：回顾→行动→复看循环" | 每周打开报告、点"已做" | 度量行为不是价值 → 已定 R7 |
| "量化"（主页） | 心力/能量/星光 = 记录天数 × 系数 | **假量化** → 已定 C1 砍 |

### 3.3 一条硬规则

任何新东西上桌前先回答：① 它在价值链哪一环（看清 / 差距 / 路 / 引领 / 改变）？② 它让一个**真实用户**今天多走了一步吗？答不出 → 不做。不是"以后再做"，是"不做，直到真实闭环跑通"。
